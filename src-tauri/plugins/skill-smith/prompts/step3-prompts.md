# Step 3：生成 prompts

> ⚠️ M2 骨架阶段：此 prompt 为占位。

## 本步目标（M3 真实实施）

为 workflow.toml 里每个 step 生成对应的 `prompts/{step}.md` 文件，
以及可选的 `prompts/base.md`（角色定位 + 全局约束）。

## 每个 step prompt 的结构

```
【角色定位】（如果 base.md 已有则省略）
【本步目标】
【工具使用指南】（按 tools_only 列表说明每个工具怎么用）
【输出约束】（格式、长度、风格）
【卡点条件】（什么情况下需要用户 confirm 才继续）
```

## 字节要求

- 每个 prompt 必须 ≥50 bytes（T3 校验规则），建议 200-1000 字符
- 内容太短 → T3 报 warning（不阻断，但质量差）
- 内容太长 → 浪费 token + 降低关键信息密度

## Few-shot 选取

从 Top-3 相似技能的 prompts/*.md 抽样本，注意：
- 不要抄整段，只学结构和语气
- 把特定业务内容替换成当前技能的场景
- 角色定位要有"人设"（不要千篇一律的"你是 AI 助手"）

## M2 骨架期的行为

简单回应"prompts 生成模拟完成，点击下一步"。
