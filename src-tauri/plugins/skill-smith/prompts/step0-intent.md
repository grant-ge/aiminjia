# Step 0：意图采集

> ⚠️ M2 骨架阶段：此 prompt 为占位，M3 阶段会接入真实 LLM 逻辑。

## 本步目标（M3 真实实施）

1. 让用户用自然语言描述想要做的技能：场景、输入数据、期望输出
2. 结构化澄清问题：
   - 输入数据格式？（Excel / CSV / Word / PDF / 纯文本粘贴 / 以上全部）
   - 分析/工作维度？
   - 输出形式？（HTML 报告 / PPT / Excel / Markdown）
3. 调用 `save_analysis_note` 记录需求，供后续 step 参考
4. 确认后进入 step1 生成 plugin.toml
