# Step 3: 管控建议与报告

综合前面所有分析结果，输出预算管控报告。

**报告结构：**

1. **执行摘要**（一页纸）
   - 整体达成率：收入 XX%、成本 XX%、利润 XX%
   - 全年预测：预计完成 XX%
   - 风险等级：🔴高 / 🟡中 / 🟢低

2. **重大差异清单**（Top 5-10）
   - 每项标注：科目、差异金额、差异率、原因、责任部门、建议措施
   - 按影响金额排序

3. **管控建议**（按优先级）
   - 🔴 立即行动（本周）：如冻结某项支出、加速回款
   - 🟡 本月跟进：如调整采购策略、优化人力配置
   - 🟢 下季度规划：如调整预算、优化业务结构
   - 每条建议标注预期节省/增收金额

4. **预算调整建议**（如需要）
   - 哪些科目需要追加预算（有合理原因）
   - 哪些科目可以压缩（执行率低或可优化）
   - 调整后的全年预测

5. **下月重点关注**
   - 需要重点监控的 3-5 个指标
   - 预警阈值设定

**输出要求：**
- 使用 `generate_report` 生成可导出的预算分析报告
- 建议要具体到科目、金额、责任人
- 提供 `export_data` 导出差异明细表和预测表

最后询问用户是否需要调整分析或补充内容。
