# Step 1: 差异分析与归因

基于 Step 0 确认的数据，执行预实差异分析。

使用 `execute_python` 计算并展示：

**整体达成率：**
1. **收入达成率** = 实际收入 / 预算收入 × 100%
2. **成本达成率** = 实际成本 / 预算成本 × 100%（越低越好）
3. **利润达成率** = 实际利润 / 预算利润 × 100%

**逐项差异分析：**
4. 按科目/部门计算绝对差异和相对差异
5. 按差异金额排序，识别 Top 5 不利差异和 Top 5 有利差异
6. 差异分类：
   - 🔴 重大不利差异（偏差 >10% 且金额 >XX 万）
   - 🟡 轻微不利差异（偏差 5-10%）
   - 🟢 有利差异（实际优于预算）

**归因分析（针对重大差异）：**
7. 价格因素 vs 数量因素
8. 可控因素 vs 不可控因素（如原材料涨价、汇率波动）
9. 一次性因素 vs 结构性因素

**输出要求：**
- 整体达成率用仪表盘式展示
- 差异明细用表格，按金额排序
- 每个重大差异标注原因分类和责任部门
- 给出初步判断：整体预算执行是否健康

展示结果后等待用户确认。
