# Step 2: 滚动预测与风险评估

## 目标

基于已实现数据进行全年滚动预测，评估预算执行风险，提出行动建议。

## 成功标准

1. 全年预测表（已实现 + 预测 + 全年预算 + 预测达成率）已以表格展示
2. risk_flags 已逐项评估并标注严重程度（🔴🟡🟢）
3. 敏感性分析（收入 -10% / 成本 +10%）已完成情景模拟
4. 预测超支科目均有具体行动建议

## 执行步骤

系统已自动完成滚动预测，结果在 [precompute_result] 中：
- `actual_to_date`：已实现累计金额
- `periods_realized`：已实现期间数
- `full_year_estimate`：全年预测金额
- `achievement_rate`：预测达成率（%）
- `gap_vs_budget`：预测 vs 预算的缺口
- `risk_flags`：自动识别的风险项

1. **全年预测展示** — 以表格形式展示：已实现 + 预测 + 全年预算 + 预测达成率
2. **风险评估** — 展示 risk_flags，并判断严重程度
3. **敏感性分析** — 用 `execute_python` 做情景分析：如收入下降10%/成本增加10% 对利润的影响
4. **行动建议** — 对预测超支的科目，提出需要立即关注的行动项

用 `export_data` 导出全年预测表（`step2_forecast.xlsx`）。

## 约束

- 滚动预测基于线性外推，必须注明假设前提（如"假设后续月份与前 N 个月均值一致"）
- 敏感性分析的情景参数（±10%）可根据用户行业特点调整

## 异常处理

- **已实现期间不足 3 个月**：警告预测可靠性低，建议仅作参考，不作为决策依据
- **precompute_result 缺失**：用 `execute_python` 基于已实现数据手动计算线性外推预测
- **风险项全部为绿**：仍需检查是否存在结构性隐患（如某科目持续接近红线）

展示预测结果后等待用户确认，告知下一步将生成完整管控建议报告。
