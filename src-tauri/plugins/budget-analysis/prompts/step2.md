# Step 2: 滚动预测与风险评估

基于已实现数据，预测全年执行情况并评估风险。

使用 `execute_python` 计算并展示：

**滚动预测：**
1. **线性外推法** — 基于已实现月份的趋势预测剩余月份
2. **季节性调整** — 如果有去年数据，用季节性系数修正
3. **全年预测** — 已实现 + 预测 = 全年预计完成数
4. **预测达成率** — 全年预计 / 全年预算

**风险评估：**
5. **收入风险** — 收入预测是否能达标？差距多少？
6. **成本风险** — 哪些成本科目有超支趋势？
7. **利润风险** — 利润预测 vs 预算的差距
8. **现金流风险** — 如有现金流数据，评估资金缺口

**敏感性分析：**
9. 如果收入下降 10%，利润会怎样？
10. 如果某项成本增加 20%，利润会怎样？
11. 盈亏平衡点在哪里？

**输出要求：**
- 全年预测用表格展示：预算 / 已实现 / 预测 / 差异
- 风险项按严重程度排序
- 敏感性分析用情景表展示
- 标注需要立即采取行动的风险项

展示结果后等待用户确认。
