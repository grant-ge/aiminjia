# Step 0: 数据加载与预算结构识别

## 目标

加载用户上传的预算相关数据，识别数据类型和结构，确认分析范围和方向。

## 成功标准

1. 数据类型（预算表/实际执行表/预实对比表）已正确识别并经用户确认
2. 维度（科目/部门/项目/时间）和度量（预算金额/实际金额/差异）已完成映射
3. 时间粒度（月度/季度/年度）和数据完整性已检查
4. 分析范围（全公司/部门/项目）和关注重点已记录到 `save_analysis_note`

## 执行步骤

用户已上传预算相关数据。

1. 使用 `load_file` 加载文件
2. 使用 `execute_python` 识别数据结构：
   - 判断数据类型：预算表、实际执行表、预实对比表
   - 识别维度：科目/部门/项目/时间
   - 识别度量：预算金额、实际金额、差异
   - 时间粒度：月度/季度/年度
   - 数据完整性：是否有缺失月份或科目

3. 向用户确认：
   - 数据是否正确识别
   - 分析范围：全公司 or 某部门/项目
   - 关注重点：
     - 整体达成率概览
     - 重大偏差科目深入分析
     - 全年预测和风险评估
   - 是否有去年同期数据可对比

4. 使用 `save_analysis_note` 记录数据结构和分析方向

**关键判断：**
- 如果只有预算表 → 聚焦预算结构合理性分析
- 如果有预实对比 → 完整差异分析 + 归因
- 如果有多期数据 → 加入趋势分析和滚动预测

## 约束

- 不对数据做任何假设，所有字段映射必须经用户确认
- 数据完整性问题必须在本步骤暴露，不可带入后续步骤

## 异常处理

- **文件无法加载**：提示用户检查文件格式（支持 xlsx/xls/csv），建议重新上传
- **预算表和实际表结构不一致**：展示两表的科目/维度差异，请用户确认对应关系
- **数据缺失月份**：列出缺失月份，询问是尚未发生还是数据遗漏
- **多 Sheet 文件**：列出所有 Sheet 名称，请用户选择要分析的 Sheet

确认后进入下一步。
