# Step 0: 数据加载与预算结构识别

用户已上传预算相关数据。你的任务：

1. 使用 `load_file` 加载文件
2. 使用 `execute_python` 识别数据结构：
   - 判断数据类型：预算表、实际执行表、预实对比表
   - 识别维度：科目/部门/项目/时间
   - 识别度量：预算金额、实际金额、差异
   - 时间粒度：月度/季度/年度
   - 数据完整性：是否有缺失月份或科目

3. 向用户确认：
   - 数据是否正确识别
   - 分析范围：全公司 or 某部门/项目
   - 关注重点：
     - 整体达成率概览
     - 重大偏差科目深入分析
     - 全年预测和风险评估
   - 是否有去年同期数据可对比

4. 使用 `save_analysis_note` 记录数据结构和分析方向

**关键判断：**
- 如果只有预算表 → 聚焦预算结构合理性分析
- 如果有预实对比 → 完整差异分析 + 归因
- 如果有多期数据 → 加入趋势分析和滚动预测

确认后进入下一步。
