# Step 2: 财务比率与杜邦分解

基于前面的结构分析，计算关键财务比率并执行杜邦分解。

使用 `execute_python` 计算并展示：

**盈利能力指标：**
1. **毛利率** = (收入 - 直接成本) / 收入
2. **营业利润率** = 营业利润 / 收入
3. **净利率** = 净利润 / 收入
4. **EBITDA 利润率** = (净利润 + 利息 + 税 + 折旧摊销) / 收入

**营运效率指标（如有资产负债表）：**
5. **总资产周转率** = 收入 / 平均总资产
6. **应收账款周转天数** = (平均应收账款 / 收入) × 365
7. **存货周转天数** = (平均存货 / 成本) × 365
8. **现金转换周期** = 应收周转天数 + 存货周转天数 - 应付周转天数

**偿债能力指标（如有资产负债表）：**
9. **流动比率** = 流动资产 / 流动负债
10. **速动比率** = (流动资产 - 存货) / 流动负债
11. **资产负债率** = 总负债 / 总资产

**杜邦分解（如有完整数据）：**
12. **ROE** = 净利率 × 资产周转率 × 权益乘数
    - 定位瓶颈：是利润率低、周转慢、还是杠杆不足？

**输出要求：**
- 用表格展示所有指标，标注同比变化和行业参考值（如有）
- 杜邦分解用树状图文字描述
- 标注 🔴 异常指标（如流动比率 <1、资产负债率 >70%）
- 给出 2-3 个关键发现
