# Step 2: 财务比率与杜邦分解

## 目标

计算核心财务比率，通过杜邦分解定位盈利能力瓶颈，评估经营健康度。

## 成功标准

1. 所有财务比率已以表格形式展示，异常值已标注 🔴🟡🟢
2. 杜邦三因素已分解，瓶颈环节已明确定位
3. 健康度评分和等级已展示，扣分原因已逐项解释
4. 异常指标的时序趋势已补充分析（如有多期数据）

## 执行步骤

系统已自动计算财务比率，结果在 [precompute_result] 中：
- `ratios`：各项财务指标（毛利率、净利率、流动比率等）
- `dupont`：杜邦三因素（净利率 × 资产周转率 × 权益乘数）
- `health_score` / `health_grade`：经营健康度评分和等级

1. **展示财务比率表** — 以表格形式展示 ratios 中所有指标，标注 🔴 异常值（流动比率<1、资产负债率>70%、净利率<0）
2. **杜邦分解解读** — 基于 dupont 数据，定位瓶颈：是利润率低、周转慢还是杠杆不足？
3. **健康度评分** — 展示 health_score 和 health_grade，并解释扣分原因
4. **深入分析** — 对异常指标用 `execute_python` 做时序趋势（如有多期数据）

用 `export_data` 导出财务比率表（`step2_ratios.xlsx`）。

## 约束

- 异常值判断使用明确阈值，不做主观评价
- 杜邦分解仅在三大报表齐备时执行，数据不足时说明限制

## 异常处理

- **缺少资产负债表**：跳过杜邦分解和偿债能力分析，聚焦盈利能力比率，告知用户分析范围受限
- **ratios 中出现极端值**：检查原始数据是否有误（如分母为零），排除数据错误后再下结论
- **health_score 缺失**：用 `execute_python` 按权重手动计算，展示计算过程

展示关键发现后等待用户确认，告知下一步将出具完整经营诊断报告。
