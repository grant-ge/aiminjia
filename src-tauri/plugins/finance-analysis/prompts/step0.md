# Step 0: 数据加载与报表识别

## 目标

加载用户上传的财务数据文件，识别报表类型和结构，确认分析方向。

## 成功标准

1. 报表类型（利润表/资产负债表/现金流量表/明细账/混合）已正确识别并经用户确认
2. 关键字段（科目名称、金额、期间、部门等）已完成映射
3. 时间范围和粒度（月度/季度/年度）已明确
4. 用户的分析目标和对比基准已记录到 `save_analysis_note`

## 执行步骤

**如果 [precompute_result] 存在且有效：**
- 直接展示识别结果（报表类型、关键字段、时间范围、数据质量）
- 跳过手动识别步骤

**如果 [precompute_result] 不存在或出错：**
1. 使用 `load_file` 加载文件
2. 使用 `execute_python` 识别数据类型和结构：
   - 判断是哪类报表：利润表（P&L）、资产负债表、现金流量表、明细账、还是混合数据
   - 识别关键字段：科目名称、金额、期间、部门等
   - 时间范围和粒度（月度/季度/年度）
   - 数据质量：缺失值、异常值、格式问题

**向用户确认：**
- 数据类型是否正确识别
- 分析目标：
  - 整体经营健康度诊断
  - 成本费用结构优化
  - 盈利能力分析
  - 现金流风险评估
- 是否有对标数据（预算、去年同期、行业基准）

使用 `save_analysis_note` 记录：
- 报表类型和字段映射
- 用户关注的分析方向
- 可用的对比基准

**关键判断逻辑：**
- 如果只有利润表 → 聚焦收入成本结构 + 盈利能力
- 如果有三大报表 → 完整杜邦分析 + 现金流诊断
- 如果是明细账 → 先聚合成报表级数据再分析
- 如果有预算数据 → 加入预算达成率分析

## 约束

- 不对数据做任何假设，所有字段映射必须经用户确认
- 数据质量问题必须在本步骤暴露，不可带入后续步骤

## 异常处理

- **文件无法加载**：提示用户检查文件格式（支持 xlsx/xls/csv），建议重新上传
- **报表类型无法识别**：展示前 10 行数据，请用户说明数据含义
- **数据严重缺失（>30%）**：警告用户分析结论可靠性受限，建议补充数据后再分析
- **多 Sheet 文件**：列出所有 Sheet 名称，请用户选择要分析的 Sheet

确认后进入下一步。
