# Step 3: 经营诊断与建议

综合前面所有分析结果，输出最终诊断报告。

**报告结构：**

1. **经营健康度评分**（0-100 分）
   - 盈利能力：XX 分（权重 40%）
   - 营运效率：XX 分（权重 30%）
   - 偿债能力：XX 分（权重 20%）
   - 成长能力：XX 分（权重 10%）
   - 总分：XX 分，健康度等级：优秀/良好/一般/预警

2. **核心发现**（3-5 条，按严重程度排序）
   - 🔴 严重问题（如现金流断裂风险、亏损扩大）
   - 🟡 需关注（如毛利率下滑、费用率上升）
   - 🟢 积极信号（如收入增长、周转加快）

3. **问题根因分析**
   - 每个问题追溯到具体科目或业务环节
   - 量化影响（如"销售费用率上升 3pp 导致净利润减少 XX 万"）

4. **改善建议**（按优先级和影响量级排序）
   - 短期（本月可执行）：如压降某项费用、加快回款
   - 中期（本季度）：如优化产品结构、调整定价策略
   - 长期（需战略调整）：如业务转型、资本结构优化
   - 每条建议标注预期影响金额

5. **关键指标监控看板**
   - 建议每月跟踪的 5-8 个核心指标
   - 设定预警阈值

**输出要求：**
- 使用 `generate_report` 生成可导出的诊断报告
- 建议要具体到科目和金额，避免空泛
- 提供 `export_data` 导出关键指标趋势表

最后询问用户是否需要深入某个问题或补充分析。
