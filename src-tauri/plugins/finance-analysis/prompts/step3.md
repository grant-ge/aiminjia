# Step 3: 经营诊断与建议

## 目标

综合前面所有分析结果，输出最终经营诊断报告，提供分级改善建议。

## 成功标准

1. 经营健康度评分已按四维度（盈利/营运/偿债/成长）加权计算并展示
2. 核心发现（3-5 条）已按 🔴🟡🟢 严重程度排序，每条含根因和量化影响
3. 改善建议已按短期/中期/长期分级，每条标注预期影响金额
4. 关键指标监控看板已输出，含预警阈值
5. 报告已通过 `generate_report` 生成可导出文档

## 执行步骤

综合前面所有分析结果，输出最终诊断报告。

**报告结构：**

1. **经营健康度评分**（0-100 分）
   - 盈利能力：XX 分（权重 40%）
   - 营运效率：XX 分（权重 30%）
   - 偿债能力：XX 分（权重 20%）
   - 成长能力：XX 分（权重 10%）
   - 总分：XX 分，健康度等级：优秀/良好/一般/预警

2. **核心发现**（3-5 条，按严重程度排序）
   - 🔴 严重问题（如现金流断裂风险、亏损扩大）
   - 🟡 需关注（如毛利率下滑、费用率上升）
   - 🟢 积极信号（如收入增长、周转加快）

3. **问题根因分析**
   - 每个问题追溯到具体科目或业务环节
   - 量化影响（如"销售费用率上升 3pp 导致净利润减少 XX 万"）

4. **改善建议**（按优先级和影响量级排序）
   - 短期（本月可执行）：如压降某项费用、加快回款
   - 中期（本季度）：如优化产品结构、调整定价策略
   - 长期（需战略调整）：如业务转型、资本结构优化
   - 每条建议标注预期影响金额

5. **关键指标监控看板**
   - 建议每月跟踪的 5-8 个核心指标
   - 设定预警阈值

**输出要求：**
- 使用 `generate_report` 生成可导出的诊断报告
- 建议要具体到科目和金额，避免空泛
- 提供 `export_data` 导出关键指标趋势表

## 约束

- 所有建议必须有数据支撑，不可空泛
- 预期影响金额为量级估算，需标注假设前提
- 报告结论不可超出数据支持的范围

## 异常处理

- **前置步骤数据不完整**：在报告中注明"受限于数据范围，以下维度未纳入评估"，列出缺失项
- **各步骤结论矛盾**：回溯原始数据核实，以数据为准，说明矛盾原因
- **用户行业特殊**：指标阈值参考行业基准调整，无行业数据时使用通用标准并注明

最后询问用户是否需要深入某个问题或补充分析。

## PPT 汇报材料（可选）

完成 HTML 报告后，**主动询问用户**："需要我把分析结果做成 PPT 汇报材料吗？"

如用户确认，调用 `generate_slides` 生成 PPTX：
- 封面页（`layout: "title_slide"`）：报告标题 + 日期
- 核心发现页：关键指标 + 一句话结论（bullets 控制在 4-6 条）
- 数据详情页：按分析维度拆分，每页一个主题
- 建议与行动页：核心建议 + 时间表
- 每页附 `notes`（演讲稿要点）

**原则**：PPT 是"说给人听"的，每页 bullets ≤ 6 条，文字精简，数字突出。
