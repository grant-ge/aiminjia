# Step 1: 收入成本结构分析

基于 Step 0 确认的数据，执行收入成本结构分析。

使用 `execute_python` 计算并展示：

**收入端分析：**
1. **收入构成** — 按产品线/业务线/客户类型拆分，计算各项占比
2. **收入趋势** — 月度/季度收入变化，标注同比增长率
3. **收入集中度** — 前 5 大客户/产品的收入占比（集中度风险）
4. **收入质量** — 如有应收数据，计算回款率和账龄分布

**成本费用端分析：**
5. **成本结构** — 直接成本 vs 间接成本，固定成本 vs 变动成本
6. **费用率趋势** — 销售费用率、管理费用率、研发费用率的变化
7. **成本弹性** — 收入增长 1% 时成本增长多少（经营杠杆）

**利润分析：**
8. **利润瀑布图** — 从收入到净利润的逐级扣减
9. **毛利率 / 净利率趋势** — 标注拐点和异常
10. **边际贡献** — 各业务线的边际贡献率排名

**输出要求：**
- 收入和成本各用一个结构表展示
- 利润瀑布用文字描述（收入 100 → 毛利 XX → 营业利润 XX → 净利润 XX）
- 标注 🔴 异常项（如某项费用率突增 >5pp）
- 给出 2-3 个初步发现

展示结果后等待用户确认，用户可以要求深入某个方向。
