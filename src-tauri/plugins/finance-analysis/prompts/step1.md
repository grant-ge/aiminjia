# Step 1: 收入成本结构分析

## 目标

拆解收入和成本费用构成，识别结构性变化和异常项目，输出收入成本结构表。

## 成功标准

1. 收入按产品线/业务线拆分占比已完成，识别出主力业务和增长/下滑业务
2. 毛利率趋势已展示，拐点已标注并说明原因
3. 费用率（销售/管理/研发）变化趋势已分析
4. 所有 anomalies 中的异常项均已追溯原因
5. 关键发现（3-5 条）已按 🔴🟡🟢 分级呈现

## 执行步骤

系统已自动完成初步计算，结果在 [precompute_result] 中：
- `gross_margin_trend`：各期毛利率趋势
- `anomalies`：自动检测到的异常变化
- `summary`：识别到的科目列表

1. **收入构成** — 按产品线/业务线拆分收入占比（用 `execute_python` 做更细粒度分析）
2. **毛利率趋势** — 基于 precompute_result 展示趋势，标注拐点
3. **费用率分析** — 销售/管理/研发费用率的变化趋势
4. **异常标注** — 对 anomalies 中的项目追溯原因

用 `export_data` 导出收入成本结构表（`step1_income_cost.xlsx`）。

## 约束

- 所有比率计算必须基于原始数据，不可使用估算值
- 异常值判断标准：同比变化 >20% 或环比变化 >15%

## 异常处理

- **收入无法按业务线拆分**：使用科目级别拆分，说明粒度限制
- **只有单期数据**：跳过趋势分析，聚焦结构占比分析，建议用户补充多期数据
- **precompute_result 缺失或异常**：用 `execute_python` 手动计算毛利率和费用率

展示关键发现（3-5条）后等待用户确认，告知下一步将进行财务比率计算和杜邦分解。
