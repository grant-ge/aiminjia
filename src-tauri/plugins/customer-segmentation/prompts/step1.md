# Step 1: RFM 分层分析

## 目标

基于 Step 0 确认的数据，计算 RFM 指标并将客户分为有业务意义的群体。

## 成功标准

1. R/F/M 三项指标已计算并展示统计摘要（均值、中位数）
2. 客户已分为至少 5-8 个有业务意义的群体
3. 各群体的定义、客户数、占比、总贡献已用表格展示
4. 最重要的 3 个群体已标注（占比最大、贡献最高、风险最高）
5. 每个群体已给出初步运营建议

## 执行步骤

系统已自动完成 RFM 分层计算，结果在 [precompute_result] 中。

**如果 [precompute_result] 有 `segment_distribution`：**
- 展示各客户群体分布（重要价值客户、重要发展客户等）
- 展示 `segment_stats` 中各群体的平均消费金额、频次、最近消费天数
- 展示 `rfm_summary` 中 R/F/M 的均值和中位数

**降级情况（有 `error` 字段）：**
- 使用 `execute_python` 手动计算 RFM

基于 Step 0 确认的数据，执行 RFM 分层。

使用 `execute_python` 计算并展示：

**RFM 指标计算：**
1. **Recency（最近消费）** — 距离最后一次消费的天数
2. **Frequency（消费频次）** — 历史总交易次数
3. **Monetary（消费金额）** — 历史总消费金额

**分层逻辑：**
- 将每个维度分为高/中/低三档（或五档）
- 组合成客户群体（如"高价值活跃客户"、"沉睡高价值客户"）
- 至少识别 5-8 个有业务意义的群体

**输出要求：**
- 用表格展示各群体的定义、客户数、占比、总贡献
- 标注最重要的 3 个群体（如占比最大、贡献最高、风险最高）
- 给出每个群体的初步运营建议

展示结果后等待用户确认。

## 约束

- 所有数值来自 execute_python 实际计算结果
- 不展示代码

## 异常处理

- **precompute 出错**：使用 `execute_python` 手动计算 RFM 指标和分层
- **数据不足**：若缺少交易日期，无法计算 R，退化为 FM 分层并告知用户；若缺少金额，退化为 RF 分层
- **用户修改需求**：用户可要求调整分层档位（三档/五档）或分层阈值，按需重新计算
