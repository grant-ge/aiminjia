# Step 3: 策略建议与报告

如果 [precompute_result] 中有 `retention_playbooks`，基于分析发现匹配对应的留存策略建议。

综合前面所有分析结果，输出最终报告。

**报告结构：**

1. **客户群体全景**
   - 各群体的规模、占比、贡献度
   - 客户结构健康度评估

2. **重点关注群体**（3-5 个）
   - 高价值活跃客户：如何维护和提升
   - 高价值沉睡客户：如何唤醒
   - 高潜力新客：如何培育
   - 流失风险客户：如何挽回

3. **差异化运营策略**
   - 每个群体的触达渠道、内容、频次建议
   - 优先级排序（ROI 最高的群体优先）

4. **关键指标监控**
   - 建议定期跟踪的指标（如流失率、复购率、客单价）

**输出要求：**
- 使用 `generate_report` 生成可导出的分析报告
- 策略要具体可执行，避免空泛建议
- 提供 `export_data` 导出客户分层名单

最后询问用户是否需要补充分析或调整策略。
