# Step 3: 策略建议与报告

## 目标

综合前面所有分析结果，输出结构化最终报告，为每个客户群体制定差异化运营策略。

## 成功标准

1. 客户群体全景表已输出（含规模、占比、贡献度）
2. 重点关注群体 3-5 个，每个有具体策略
3. 差异化运营策略含触达渠道、内容、频次建议
4. 关键监控指标已列出（流失率、复购率、客单价等）
5. 报告已通过 `generate_report` 生成，客户名单已通过 `export_data` 导出

## 执行步骤

如果 [precompute_result] 中有 `retention_playbooks`，基于分析发现匹配对应的留存策略建议。

综合前面所有分析结果，输出最终报告。

**报告结构：**

1. **客户群体全景**
   - 各群体的规模、占比、贡献度
   - 客户结构健康度评估

2. **重点关注群体**（3-5 个）
   - 高价值活跃客户：如何维护和提升
   - 高价值沉睡客户：如何唤醒
   - 高潜力新客：如何培育
   - 流失风险客户：如何挽回

3. **差异化运营策略**
   - 每个群体的触达渠道、内容、频次建议
   - 优先级排序（ROI 最高的群体优先）

4. **关键指标监控**
   - 建议定期跟踪的指标（如流失率、复购率、客单价）

**输出要求：**
- 使用 `generate_report` 生成可导出的分析报告
- 策略要具体可执行，避免空泛建议
- 提供 `export_data` 导出客户分层名单

最后询问用户是否需要补充分析或调整策略。

## PPT 汇报材料（可选）

完成 HTML 报告后，**主动询问用户**："需要我把分析结果做成 PPT 汇报材料吗？"

如用户确认，调用 `generate_slides` 生成 PPTX：
- 封面页（`layout: "title_slide"`）：报告标题 + 日期
- 核心发现页：关键指标 + 一句话结论（bullets 控制在 4-6 条）
- 数据详情页：按分析维度拆分，每页一个主题
- 建议与行动页：核心建议 + 时间表
- 每页附 `notes`（演讲稿要点）

**原则**：PPT 是"说给人听"的，每页 bullets ≤ 6 条，文字精简，数字突出。

## 约束

- 所有结论必须有前序步骤的数据支撑，不编造数据
- 策略建议必须可执行，避免空泛表述
- 不展示代码

## 异常处理

- **precompute 出错**：不使用 `retention_playbooks`，基于前序步骤分析结果直接生成策略建议
- **数据不足**：若前序步骤某维度缺失（如无生命周期分析），报告中跳过该部分并说明原因
- **用户修改需求**：用户可要求调整策略优先级、补充分析维度或修改报告结构，按需重新生成
