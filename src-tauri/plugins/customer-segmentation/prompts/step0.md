# Step 0: 数据加载与探查

用户已上传客户数据文件。你的任务：

1. 使用 `load_file` 加载文件
2. 使用 `execute_python` 快速探查数据结构：
   - 客户数量、字段列表
   - 关键字段：客户 ID、交易日期、交易金额、交易次数等
   - 时间范围
   - 缺失值情况

3. 向用户确认：
   - 数据是否正确加载
   - 分析目标（提升复购/识别流失风险/精准营销）
   - 是否有特定的客户群体需要重点关注

4. 使用 `save_analysis_note` 记录用户需求

**输出格式示例：**
```
已加载客户数据，共 5,678 位客户，交易记录时间范围 2024-01 至 2025-12。

数据字段：
- 客户 ID、交易日期、交易金额、产品类别、渠道来源

请问你的分析目标是什么？
1. 识别高价值客户，制定 VIP 策略
2. 发现流失风险客户，制定挽回计划
3. 全面分层，制定差异化运营策略
```

确认后进入下一步。
