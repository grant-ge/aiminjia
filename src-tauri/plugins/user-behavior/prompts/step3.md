# Step 3: 产品优化建议

## 目标

综合前面所有分析结果，输出产品优化建议报告，给出可执行的功能优化、用户激活和留存提升策略。

## 成功标准

1. 功能优化建议已给出（优化/下线/推广分类）
2. 用户激活策略已明确（引导新用户完成关键行为的具体方案）
3. 留存提升策略按用户层差异化制定
4. 产品路线图建议已给出（基于用户行为的功能优先级排序）
5. 报告已通过 `generate_report` 生成

## 执行步骤

如果 [precompute_result] 中有 `engagement_playbooks`，基于分析发现匹配对应的用户运营策略建议。

1. **功能优化建议** — 哪些功能需要优化/下线/推广
2. **用户激活策略** — 如何引导新用户完成关键行为
3. **留存提升策略** — 针对不同用户层的差异化策略
4. **产品路线图建议** — 基于用户行为的功能优先级

使用 `generate_report` 生成报告，`export_data` 导出数据。

## 约束

- 每条建议标注预期影响和实施难度
- 建议按优先级排序（高影响 + 低难度优先）
- 所有建议必须有数据支撑，引用前序步骤的分析结果

## 异常处理

- **precompute 出错**：不使用 `engagement_playbooks`，基于前几步分析结果直接撰写优化建议
- **前序步骤数据不完整**：在报告中标注"因缺少 XX 数据，以下建议基于有限分析"，避免过度推断
- **用户修改报告侧重点**：按用户要求调整报告结构，重新组织已有分析结论

最后询问用户是否需要深入某个方向或调整策略。

## PPT 汇报材料（可选）

完成 HTML 报告后，**主动询问用户**："需要我把分析结果做成 PPT 汇报材料吗？"

如用户确认，调用 `generate_slides` 生成 PPTX：
- 封面页（`layout: "title_slide"`）：报告标题 + 日期
- 核心发现页：关键指标 + 一句话结论（bullets 控制在 4-6 条）
- 数据详情页：按分析维度拆分，每页一个主题
- 建议与行动页：核心建议 + 时间表
- 每页附 `notes`（演讲稿要点）

**原则**：PPT 是"说给人听"的，每页 bullets ≤ 6 条，文字精简，数字突出。
