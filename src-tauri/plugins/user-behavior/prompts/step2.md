# Step 2: 参与度与留存关联

## 目标

构建参与度评分模型，识别高参与度用户特征，分析参与度与留存的关联性，找到驱动长期留存的关键行为。

## 成功标准

1. 参与度评分模型已构建（综合活跃天数、使用时长、功能深度）
2. 高参与度用户的共同特征已识别
3. 参与度与留存率的关联关系已量化展示
4. 激活关键行为已识别（与长期留存强相关的行为）
5. 各用户层的差异化运营方向已明确

## 执行步骤

系统已自动完成功能使用分析，结果在 [precompute_result] 中。

**如果 [precompute_result] 有 `feature_ranking`：**
- 展示功能使用频率排名
- 展示功能渗透率（各功能的用户覆盖率）
- 展示常见用户路径（Top paths）

**降级情况：**
- 使用 `execute_python` 手动计算

1. **参与度评分** — 综合活跃天数、使用时长、功能深度
2. **高参与度用户特征** — 他们有什么共同点
3. **参与度与留存关联** — 参与度高的用户留存是否更好
4. **激活关键行为** — 哪些行为与长期留存强相关

## 约束

- 参与度评分维度权重需基于数据分布确定，不硬编码
- 关联分析需区分相关性和因果性

## 异常处理

- **precompute 出错**：降级为 `execute_python` 手动计算功能排名和路径
- **数据不足以建模**：如用户数过少或时间跨度不够，降级为定性分析，说明"样本量不足以建立统计显著的参与度模型"
- **用户修改评分维度**：按用户要求调整参与度评分的维度和权重

展示结果后等待用户确认。
