# Step 0: 数据加载与用户分层

## 目标

加载用户上传的行为数据文件，识别数据结构，执行初步用户分层，与用户确认分析方向。

## 成功标准

1. 数据文件成功加载，用户ID列、事件列、时间列已识别
2. 事件类型分布已统计（各事件类型的数量和占比）
3. 用户分层完成（按活跃度/功能深度/价值至少一个维度）
4. 用户已确认分析目标（功能优化/用户激活/留存提升）
5. 分层结果已通过 `save_analysis_note` 记录

## 执行步骤

用户已上传行为数据文件。系统已自动识别数据结构，结果在 [precompute_result] 中。

**如果 [precompute_result] 存在且有效：**
- 直接展示识别结果（用户ID列、事件列、时间列、事件类型分布、用户数、时间范围）
- 向用户确认分析方向

**如果 [precompute_result] 不存在或出错：**
1. 使用 `load_file` 加载用户行为数据
2. 使用 `execute_python` 识别数据结构：事件类型、用户ID、时间戳、属性字段
3. 向用户确认分析目标：功能优化/用户激活/留存提升
4. 执行用户分层：按活跃度、功能使用深度、价值分层
5. 使用 `save_analysis_note` 记录分层结果

## 约束

- 不预设分层标准，根据数据实际分布确定分层阈值
- 不跳过确认步骤直接进入分析

## 异常处理

- **precompute 出错**：降级为 `load_file` + `execute_python` 手动加载和识别
- **数据不足**：如缺少用户ID或事件类型字段，告知用户数据限制，建议补充必要字段
- **用户修改分析方向**：重新记录 `save_analysis_note`，按新方向调整后续分析

确认后进入下一步。
