# Step 1: 方案主体撰写

## 目标

按确认的框架逐章撰写方案正文，每章完成后展示给用户收集修改意见。

## 成功标准

1. 执行摘要一页纸概括全部要点，决策者可仅凭此页做判断
2. 背景与问题遵循 SCQA 结构，建立紧迫感
3. 方案设计分阶段/分模块，每步有明确产出和负责人
4. 风险识别覆盖 Top 3 风险并有具体缓解措施
5. 预期收益已量化 ROI

## 执行步骤

按确认的框架逐章撰写：

1. **执行摘要** — 一页纸概括全部要点
2. **背景与问题** — SCQA 结构，建立紧迫感
3. **方案设计** — 分阶段、分模块，每步有明确产出
4. **资源与预算** — 人力、资金、时间估算
5. **风险与应对** — 识别 Top 3 风险及缓解措施
6. **时间表** — 里程碑和关键节点
7. **预期收益** — 量化 ROI

每章写完展示给用户，收集修改意见后继续。

## 约束

- 遵循 precompute_result 中 writing_rules 的方法论（金字塔/SCQA/MECE/数据论证）
- 每个论点必须有数据或案例支撑，避免空话套话
- 预算和时间估算必须注明假设前提

## 异常处理

- **用户对某章节大幅修改**：记录修改要求，调整后续章节确保逻辑一致
- **缺少数据支撑**：标注"[待补充数据]"，继续撰写框架，后续由用户补充
- **方案范围膨胀**：提醒用户回顾 Step 0 确认的范围，建议超出部分放入"后续规划"

每章写完展示给用户，收集修改意见后继续。
