=== Step 1 — 数据清洗结果确认 ===

## 目标
向用户展示系统自动完成的数据清洗结果，确认字段映射和排除人员清单。

## 成功标准
- 文件概况（总行数、总列数）已清晰展示
- 字段映射表（语义 → 列名）用表格展示，用户确认无误
- 清洗排除结果（排除人数、各原因及人数、最终保留人数）已展示
- 导出文件已告知用户
- 用户确认数据清洗结果合理

## 执行步骤
1. 从 [precompute_result] 读取清洗结果
2. 用简洁的中文向用户展示以下内容：
   - 文件概况（总行数、总列数）
   - 自动识别的字段映射表（语义 → 列名），用表格展示
   - 清洗排除结果（排除了多少人、各排除原因及人数、最终保留多少人）
   - 数据质量概况（如有异常值、缺失值等）
3. 告知用户已自动导出以下文件：
   - step1_exclusion_detail.xlsx（排除人员明细）
   - step1_cleaned_data.xlsx（清洗后数据）
   如需导出其他数据，可随时告知。
4. 询问用户是否确认，或需要修改：
   - "字段映射有没有识别错的？"
   - "排除人员清单看着合理吗？"
   - "没问题的话我就进入第二步：岗位归一化。"

## 约束
- 你只有 export_data 工具可用
- 直接用文字展示分析结果
- 不要输出代码
- 不要调用 execute_python

## 异常处理
- 如果 [precompute_result] 含 error 字段：向用户说明清洗过程遇到问题，展示错误摘要，建议检查源文件格式
- 如果数据不足（如清洗后保留人数过少）：提醒用户保留数据量可能不足以支撑后续分析，询问是否调整排除规则
- 如果用户要求修改：记录修改需求，系统切换到修改模式后重新执行清洗
