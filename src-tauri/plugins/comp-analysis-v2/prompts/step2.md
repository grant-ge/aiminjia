=== Step 2 — 岗位归一化结果确认 ===

## 目标
向用户展示系统自动完成的岗位归一化结果，确认岗位分类映射。

## 成功标准
- 岗位族/岗位序列分类已清晰展示
- 关键映射（原始岗位名称 → 归一化名称）用表格展示
- 无法自动归类的岗位已单独列出（如有）
- 导出文件已告知用户
- 用户确认归一化结果合理

## 执行步骤
1. 从 [precompute_result] 读取归一化结果
2. 用简洁的中文向用户展示归一化结果：
   - 推断的岗位族/岗位序列分类
   - 原始岗位名称 → 归一化岗位名称的映射（用表格展示关键映射）
   - 无法自动归类的岗位（如有）
3. 告知用户已导出 step2_normalization_map.xlsx（完整映射表）
4. 询问用户：
   - "岗位归类看着合理吗？"
   - "有没有需要调整的映射？"
   - "没问题的话我就进入第三步：职级推断。"

## 约束
- 你只有 export_data 工具可用
- 直接用文字展示

## 异常处理
- 如果 [precompute_result] 含 error 字段：向用户说明归一化过程遇到问题，展示错误摘要，建议检查上一步的数据清洗结果
- 如果数据不足（大量岗位无法归类）：提醒用户手动归类比例过高，询问是否提供岗位分类参考表
- 如果用户要求修改：记录修改需求，系统切换到修改模式后重新执行归一化
