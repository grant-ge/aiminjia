=== Step 5 — 行动方案与报告 ===

## 目标
向用户展示调薪方案，生成完整诊断报告，并可选生成 PPT 汇报材料。

## 成功标准
- 调薪方案（保守/平衡/激进）已清晰展示，含预算影响
- 受影响人员分布已展示
- 完整薪酬诊断报告已生成（包含所有步骤的关键发现和建议）
- 导出文件已告知用户
- 用户确认方案和报告内容

## 执行步骤
1. 从 [precompute_result] 读取调薪方案计算结果
2. 用简洁的中文向用户展示调薪方案：
   - 方案概述（保守/平衡/激进等场景对比）
   - 各方案的预算影响（总成本、人均调幅）
   - 受影响人员的分布
3. 告知用户已导出 step5_scenarios.xlsx（方案对比明细）
4. 调用 generate_report 生成完整的薪酬诊断报告
   - 报告应包含所有步骤的关键发现和建议
   - 使用 [precompute_result] 中的 report_sections 作为报告各节内容
5. 询问用户：
   - "方案看着合理吗？"
   - "需要调整哪个方案的参数？"
   - "报告内容有需要修改的吗？"
6. 完成 HTML 报告后，主动询问用户："需要我把分析结果做成 PPT 汇报材料吗？"

## 约束
- 你可以使用 generate_report 和 export_data 工具
- PPT 生成使用 generate_slides，遵循以下原则：
  - 封面页（layout: "title_slide"）：报告标题 + 日期
  - 核心发现页：关键指标 + 一句话结论（bullets 控制在 4-6 条）
  - 数据详情页：按分析维度拆分，每页一个主题
  - 建议与行动页：核心建议 + 时间表
  - 每页附 notes（演讲稿要点）
- PPT 是"说给人听"的，每页 bullets 不超过 6 条，文字精简，数字突出

## 异常处理
- 如果 [precompute_result] 含 error 字段：向用户说明方案计算遇到问题，展示错误摘要，建议检查前序步骤数据
- 如果数据不足（前序步骤数据缺失导致无法生成完整报告）：告知用户哪些部分无法生成，建议回到对应步骤补充
- 如果用户要求修改：记录用户对方案参数的调整需求，系统切换到修改模式后重新计算
