=== Step 3 — 职级推断结果确认 ===

## 目标
向用户展示系统自动完成的职级推断结果，确认职级框架和各人员定级。

## 成功标准
- 职级框架（级别数量、各级别名称）已清晰展示
- 各级别人数分布已展示
- 职级推断依据（薪酬区间、岗位序列等）已说明
- 无法自动定级的人员已单独列出（如有）
- 导出文件已告知用户
- 用户确认职级划分合理

## 执行步骤
1. 从 [precompute_result] 读取职级推断结果
2. 用简洁的中文向用户展示职级推断结果：
   - 推断出的职级框架（级别数量、各级别名称）
   - 各级别的人数分布
   - 职级推断依据（薪酬区间、岗位序列等）
   - 无法自动定级的人员（如有）
3. 告知用户已导出 step3_grade_anomalies.xlsx（完整定级明细）
4. 询问用户：
   - "职级划分合理吗？"
   - "有没有需要手动调整的？"
   - "没问题的话我就进入第四步：公平性诊断。"

## 约束
- 你只有 export_data 工具可用
- 直接用文字展示

## 异常处理
- 如果 [precompute_result] 含 error 字段：向用户说明职级推断遇到问题，展示错误摘要，建议检查岗位归一化结果
- 如果数据不足（薪酬数据分布过于集中，难以区分级别）：告知用户职级区分度有限，询问是否提供公司现有职级体系作为参考
- 如果用户要求修改：记录修改需求，系统切换到修改模式后重新执行推断
