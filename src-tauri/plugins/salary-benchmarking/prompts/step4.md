=== Step 4 — 调整建议与报告 ===

## 目标
基于前三步分析，生成薪酬调整建议、预算估算和完整报告。

## 成功标准
- 红圈/绿圈员工处理方案已给出具体操作步骤
- 新老倒挂解决方案已明确
- 薪酬带设计/优化建议（带宽、级差、策略定位）已给出
- 预算估算（总成本、分步预算）已计算
- 完整 HTML 报告已通过 generate_report 生成
- 用户已确认最终报告

## 执行步骤
1. 薪酬调整建议：
   - 红圈员工处理方案（冻结调薪/分步调整）
   - 绿圈员工补偿方案（一次性调整/分步追赶）
   - 新老倒挂解决方案
   - 关键岗位薪酬竞争力提升方案
2. 薪酬带设计/优化建议：
   - 建议的薪酬带宽和级差
   - 薪酬策略定位（领先/跟随/滞后）
3. 预算估算：
   - 各类调整的总成本
   - 分步实施的预算分配
4. 调用 generate_report 生成完整报告
5. 询问用户确认

## 约束
- 你可以使用 generate_report 和 export_data 工具
- 调整建议必须基于前三步的实际数据，不可脱离数据空谈
- 预算估算需给出合理假设和计算依据

## 异常处理
- 如果 [precompute_result] 含 error 字段：向用户展示错误原因，建议检查前序步骤是否都已确认通过
- 如果数据不足：说明哪些建议因数据不足只能给出方向性参考，标注"需补充数据后细化"
- 如果用户要求修改：根据用户反馈调整建议内容，重新生成报告

## PPT 汇报材料（可选）

完成 HTML 报告后，**主动询问用户**："需要我把分析结果做成 PPT 汇报材料吗？"

如用户确认，调用 `generate_slides` 生成 PPTX：
- 封面页（`layout: "title_slide"`）：报告标题 + 日期
- 核心发现页：关键指标 + 一句话结论（bullets 控制在 4-6 条）
- 数据详情页：按分析维度拆分，每页一个主题
- 建议与行动页：核心建议 + 时间表
- 每页附 `notes`（演讲稿要点）

**原则**：PPT 是"说给人听"的，每页 bullets ≤ 6 条，文字精简，数字突出。
