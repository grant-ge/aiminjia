# Step 0: 合同加载与类型识别

## 目标

加载合同文件，识别合同类型和基本信息，与用户确认审查方向。

## 成功标准

1. 合同文件成功加载且内容可读
2. 正确识别合同类型（采购/销售/服务/劳动/保密/授权等）
3. 提取出甲乙方、签订日期、合同金额、履行期限等基本信息
4. 用户确认审查重点方向

## 执行步骤

1. 使用 `load_file` 加载合同文件
2. 识别合同类型：采购/销售/服务/劳动/保密/授权等
3. 提取基本信息：甲乙方、签订日期、合同金额、履行期限
4. 向用户确认：审查重点（风险识别/合规检查/与模板对比）
5. 使用 `save_analysis_note` 记录合同类型和审查方向

确认后进入下一步。

## 约束

- 仅提取文本中明确存在的信息，不推测缺失字段的值
- 合同类型识别须基于合同标题和条款内容，不凭文件名猜测

## 异常处理

- 文件加载失败或内容为空：提示用户检查文件格式，支持 PDF/DOCX/TXT，建议重新上传
- 无法识别合同类型：列出可能的类型选项，请用户手动选择
- 基本信息缺失严重（如无甲乙方信息）：标注缺失项，提示可能影响后续审查完整性
