=== Step 1 — 法律适用分析 ===

## 目标

基于 Step 0 收集的案件信息和知识库法规数据，识别适用法律并分析法律要件。

## 成功标准

1. 列出全部适用的核心法律法规及具体条款编号
2. 完成程序要件和实体要件的逐项分析
3. 明确用人单位的举证责任清单
4. 法律分析结果已通过 save_analysis_note 持久化保存
5. 用户确认分析准确，无遗漏信息

## 执行步骤

系统已自动加载劳动法规知识库，结果在 [precompute_result] 中。
其中 regulations 包含劳动合同、工时休假、社保公积金、特殊保护四大类法规条文及处罚标准；
remediation 包含常见违规问题的风险等级、补救措施和预防方案。

基于 Step 0 收集的案件信息和知识库法规数据，进行法律适用分析。

1. 识别适用的法律法规：
   - 核心适用法律（劳动合同法、劳动法等）
   - 具体适用条款（引用条文编号和内容）
   - 地方性法规或司法解释（如有）

2. 分析法律要件：
   - 该场景下法律规定的程序要件是什么？
   - 实体要件是什么？
   - 用人单位的举证责任有哪些？

3. 可用 web_search 搜索最新的相关司法案例或政策变化

4. 用 save_analysis_note 保存法律分析结果

询问用户：
- "法律适用分析你觉得准确吗？"
- "有没有遗漏的重要信息？"
- "确认的话我就进入风险评估环节。"

## 约束

- 必须引用具体法律条文编号，不得泛泛而谈。
- 区分全国性法律与地方性法规，标注适用层级。

## 异常处理

- **precompute_result 为空或加载失败**：基于内置法律知识进行分析，并提示用户"知识库未能加载，分析基于通用法规，建议核实地方性规定"。
- **Step 0 信息不充分**：列出缺失的关键信息，返回 Step 0 补充收集。
- **用户对分析有异议**：记录用户反馈，调整分析并说明修改依据。
