# Step 1: OKR 初稿制定

## 目标

根据业务背景和战略重点，制定符合 OKR 原则的初稿并完成原则检验。

## 成功标准

1. 提出 3-5 个 Objective，每个定性且鼓舞人心
2. 每个 O 配 3-5 个 Key Result，全部可量化且有基线和目标值
3. 所有 O 和 KR 通过 SMART 检验
4. 不符合原则的地方已标注并给出修改建议
5. 初稿已展示给用户等待反馈

## 执行步骤

1. 根据背景和战略重点，提出 3-5 个 Objective
2. 每个 O 配 3-5 个 Key Result
3. 检验每个 O 和 KR 是否符合原则
4. 标注不符合原则的地方并给出修改建议

展示初稿后等待用户反馈。

## 约束

- O 必须是定性描述，不含数字
- KR 必须可量化，有明确基线和目标值
- 不超过 5 个 O，避免聚焦不足

## 异常处理

- **precompute 出错**：直接根据 OKR 核心原则制定初稿，不依赖案例库和指标库
- **信息不足**：在 KR 中标记 `[待确认：基线值/目标值]`，提示用户补充业务数据
- **用户修改方向**：确认修改意图后调整对应 O 或 KR，保留用户已认可的部分
