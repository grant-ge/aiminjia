=== Step 4 — 升级路线图与报告 ===

## 目标

综合前三步成果，生成24个月分阶段升级路线图和完整成熟度评估报告，并可选生成PPT汇报材料。

## 成功标准

1. 24个月路线图包含4个阶段，每阶段有明确行动项和里程碑
2. 每阶段资源需求（预算/人力/时间）已量化
3. 推荐工具和资源清单已列出
4. 完整报告已通过 generate_report 生成
5. 用户确认路线图可行性

## 执行步骤

1. 设计24个月分阶段升级路线图：
   - **Phase 1（1-3个月）：基础建设**
     * 数据清理和标准化
     * 基础报表规范化
     * 关键工具采购/部署
   - **Phase 2（4-6个月）：能力提升**
     * 团队培训计划
     * BI仪表盘搭建
     * 首批分析项目启动
   - **Phase 3（7-12个月）：深化应用**
     * 高级分析方法引入
     * 业务场景拓展
     * 内部宣传和推广
   - **Phase 4（13-24个月）：体系成熟**
     * 预测模型建设
     * 决策支持体系完善
     * ROI评估和持续优化

2. 每阶段包含：
   - 具体行动项（3-5项）
   - 资源需求（预算、人力、时间）
   - 里程碑和验收标准
   - 风险和应对

3. 推荐工具和资源清单

4. 调用 generate_report 生成完整报告，包含：
   - 企业数据分析现状摘要
   - 16题评估结果和雷达图数据
   - 成熟度级别判定（含与同行对比）
   - 差距分析详情
   - 24个月升级路线图
   - 推荐工具和培训资源
   - 投资回报预期

5. 询问用户：
   - "路线图你觉得可行吗？"
   - "预算和时间安排需要调整吗？"
   - "报告内容有需要修改的吗？"

你可以使用 generate_report 工具。

---

## PPT 汇报材料（可选）

完成 HTML 报告后，**主动询问用户**："需要我把分析结果做成 PPT 汇报材料吗？"

如用户确认，调用 `generate_slides` 生成 PPTX：
- 封面页（`layout: "title_slide"`）：报告标题 + 日期
- 核心发现页：关键指标 + 一句话结论（bullets 控制在 4-6 条）
- 数据详情页：按分析维度拆分，每页一个主题
- 建议与行动页：核心建议 + 时间表
- 每页附 `notes`（演讲稿要点）

**原则**：PPT 是"说给人听"的，每页 bullets ≤ 6 条，文字精简，数字突出。

## 约束

- 路线图必须基于 Step 3 的差距分析，行动项必须对应已识别的缺口
- 资源需求估算需考虑 Step 0 收集的企业规模和行业特点
- 不得给出超出企业承受能力的预算建议（参考企业规模合理估算）

## 异常处理

- 缺少前序步骤数据 → 不得凭记忆拼凑报告，提示需先完成缺失步骤
- generate_report 调用失败 → 以结构化文本形式输出报告核心内容，告知用户稍后可重试生成
- 用户要求大幅调整路线图 → 记录调整意见，重新生成对应阶段，无需全部重来
- 用户预算或时间约束与建议冲突 → 提供"精简版"路线图，标注哪些行动项被裁减及影响
