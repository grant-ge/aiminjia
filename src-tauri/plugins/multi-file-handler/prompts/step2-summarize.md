# Step 2：批量摘要（mode=summarize_all）

## 目标

对 step1 加载的每份文档生成**单文件摘要**，再给出**整体总结**（跨文件提取共性/差异/趋势）。

适用：多份研报、多份合同、多份会议纪要、多份简历。

## 执行要点

### 1. 单文件摘要

对每个文档生成结构化摘要：

```
## 文件 1: Q3_report.pdf

- **主题**：Q3 业绩回顾
- **日期**：2025-09-30
- **关键数据**：营收 1.2 亿（+15%）、客户 320（+12）
- **三大结论**：
  1. 华东区营收领跑
  2. SaaS 续费率创新高
  3. 硬件业务疲软
- **行动项**：扩 SaaS 团队 / 硬件转代理模式
```

字段因文档类型而异：
- **研报/报告** → 数据 + 结论 + 趋势
- **合同** → 主体 + 金额 + 关键条款 + 风险
- **会议纪要** → 参会人 + 议题 + 决议 + 行动项
- **简历** → 姓名 + 经验 + 技能 + 亮点

### 2. 跨文件对比 / 聚合

基于各文件摘要做高层分析：

- **趋势对比**（如 Q1-Q4 报告）：指标变化曲线
- **共性提取**（如多份合同）：常见条款、金额区间、风险点
- **差异归纳**（如多份简历）：背景差异谱系、技能覆盖率

### 3. 导出

- `summary.html`：含各文件摘要 + 整体分析 + 图表（趋势用折线图、分布用饼图）
- `summary.xlsx`：结构化字段表（每行一个文件，列是字段）

### 4. chat 总结

```
## 批量摘要完成

已处理 4 份 Q1-Q4 报告：

| 季度 | 营收 | 客户数 | 核心结论 |
|------|------|-------|---------|
| Q1 | 0.8 亿 | 280 | 产品上线、获客为主 |
| Q2 | 0.9 亿 | 295 | 续费率 92% |
| Q3 | 1.2 亿 | 320 | 华东领跑、SaaS 爆发 |
| Q4 | 1.4 亿 | 345 | 年度目标超额 12% |

🎯 年度洞察：客户数稳步增长（+65 全年），营收加速（Q3/Q4 增长 33%）。

📁 已导出：
- q1_q4_summary.html（图表 + 趋势分析）
- q1_q4_summary.xlsx（结构化字段）

继续生成完整汇总报告？
```

## 陷阱

- **信息密度 vs 篇幅**：长文档容易过度压缩失去关键细节。默认摘要 ~300 字 / 份；用户要详细就调高
- **事实准确性**：LLM 容易编造数字，从原文提取数值时**双重核对**（在 chat 里引用原文片段）
- **时间顺序**：多份时间序列文档要先按日期排序再分析
- **语言混合**：有中英混合时要维持术语一致
