# Step 1: 初稿撰写

## 目标

根据文档类型和用户需求，撰写符合商务写作规范的完整初稿。

## 成功标准

1. 初稿结构符合对应文档类型的标准格式
2. 金字塔原理贯穿全文（结论先行、重点前置）
3. 语气和详细程度匹配目标读者
4. 所有关键信息已融入文档
5. 初稿已展示给用户等待反馈

## 执行步骤

根据文档类型和用户需求撰写初稿：

- 邮件：主题行 + 正文 + 结尾行动点
- 报告：执行摘要 + 正文各章节
- 纪要：会议信息 + 讨论要点 + 决策 + 待办
- PPT 大纲：逻辑结构 + 各页核心观点

展示初稿后等待用户反馈。

## 约束

- 严格按照确认的文档类型结构撰写
- 不添加用户未提供的事实或数据

## 异常处理

- **precompute 出错**：直接根据 base.md 中的文档类型要点和用户需求撰写，不依赖模板
- **信息不足**：在初稿中用 `[待补充：xxx]` 标记缺失部分，告知用户需要补充
- **用户修改方向**：确认修改意图后重新撰写，不在原稿上打补丁
