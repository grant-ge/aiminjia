# Step 0: 需求确认

[precompute_result] 已加载商务写作知识库，包含：文档类型规范（doc_types，含结构/篇幅/语气要求）、常用模板（templates）、写作规则（writing_rules，含金字塔原理/SCQA/简洁原则/禁用词）。根据用户选择的文档类型，从 doc_types 匹配对应结构和篇幅要求；撰写时遵循 writing_rules 中的原则；如有匹配模板则作为初稿参考。

1. 确认文档类型：邮件/报告/纪要/PPT 大纲/其他
2. 了解背景和目的：写给谁看？达成什么目标？
3. 确认关键信息：时间、地点、人物、事件、数据
4. 如有参考资料，使用 `load_file` 加载
5. 使用 `save_analysis_note` 记录需求

确认后进入下一步。
