# Step 0: 数据加载与指标识别

## 目标

加载用户上传的运营数据文件，识别数据结构和业务类型，与用户确认分析方向。

## 成功标准

1. 数据文件成功加载，行数和列数已确认
2. 业务场景已识别（电商/SaaS/内容/O2O/零售）
3. 关键指标字段已映射（日期、用户ID、渠道、金额等）
4. 用户已确认分析方向和北极星指标
5. 分析上下文已通过 `save_analysis_note` 记录

## 执行步骤

用户已上传运营数据文件。系统已自动识别数据结构，结果在 [precompute_result] 中。

**如果 [precompute_result] 存在且有效：**
- 直接展示识别结果（业务场景、关键指标字段、数据规模）
- 向用户确认分析方向

**如果 [precompute_result] 不存在或出错：**
1. 使用 `load_file` 加载文件
2. 使用 `execute_python` 识别数据结构：
   - 数据类型：流量数据、交易数据、用户行为数据、渠道投放数据
   - 关键字段：日期、用户ID、渠道、行为事件、金额等
   - 时间范围和粒度
   - 数据量级（日活、月交易量等）

3. 向用户确认：
   - 业务类型（电商/SaaS/内容/O2O/零售）
   - 分析目标：
     - 整体运营健康度（大盘指标趋势）
     - 转化漏斗优化（定位流失环节）
     - 渠道效率评估（ROI 对比）
     - 用户留存分析（Cohort 分析）
   - 核心北极星指标是什么（GMV/DAU/付费用户数/...）

4. 使用 `save_analysis_note` 记录业务类型、数据结构、分析方向

## 约束

- 不预设业务类型，必须从数据中识别或由用户确认
- 不跳过确认步骤直接进入分析

## 异常处理

- **precompute 出错**：降级为 `load_file` + `execute_python` 手动加载和识别
- **数据不足**：如数据行数过少或缺少关键字段（如无日期列、无用户ID列），告知用户数据限制，建议补充
- **用户修改分析方向**：重新记录 `save_analysis_note`，按新方向调整后续分析

确认后进入下一步。
