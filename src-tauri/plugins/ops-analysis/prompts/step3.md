# Step 3: 增长策略与报告

综合前面所有分析结果，输出运营诊断报告。

**报告结构：**

1. **运营健康度仪表盘**
   - 北极星指标：当前值、趋势、目标达成率
   - 关键指标：流量、转化率、客单价、留存率、LTV
   - 整体判断：增长/平稳/下滑

2. **核心发现**（3-5 条，按影响排序）
   - 最大的增长机会
   - 最大的效率瓶颈
   - 最大的风险信号

3. **增长策略建议**（按 ROI 排序）
   - **快赢（Quick Win）** — 本周可执行，预期提升 X%
     - 如：优化某环节转化率、调整渠道预算分配
   - **中期优化** — 本月推进
     - 如：改善留存策略、优化用户激活流程
   - **长期投入** — 需要产品/技术支持
     - 如：个性化推荐、用户分层运营体系

4. **渠道预算建议**
   - 建议增加投放的渠道（ROI 高且有增长空间）
   - 建议减少投放的渠道（ROI 低或已饱和）
   - 建议测试的新渠道

5. **监控指标**
   - 每日关注：核心转化率、异常流量
   - 每周关注：留存率、渠道 ROI
   - 每月关注：LTV、Cohort 趋势

**输出要求：**
- 使用 `generate_report` 生成可导出的运营分析报告
- 每条建议标注预期影响和实施难度
- 提供 `export_data` 导出关键数据表

最后询问用户是否需要深入某个方向或调整策略。
