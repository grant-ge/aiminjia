# Step 3: 增长策略与报告

## 目标

综合前面所有分析结果，输出运营诊断报告，给出可执行的增长策略建议。

## 成功标准

1. 运营健康度仪表盘已生成（北极星指标 + 关键指标 + 整体判断）
2. 核心发现 3-5 条，按影响排序
3. 增长策略建议按快赢/中期/长期分层，每条标注预期影响和实施难度
4. 渠道预算建议已给出（增加/减少/测试）
5. 监控指标清单已输出（每日/每周/每月）

## 执行步骤

如果 [precompute_result] 中有 `growth_playbooks`，基于分析发现匹配对应的增长策略建议。

**报告结构：**

1. **运营健康度仪表盘**
   - 北极星指标：当前值、趋势、目标达成率
   - 关键指标：流量、转化率、客单价、留存率、LTV
   - 整体判断：增长/平稳/下滑

2. **核心发现**（3-5 条，按影响排序）
   - 最大的增长机会
   - 最大的效率瓶颈
   - 最大的风险信号

3. **增长策略建议**（按 ROI 排序）
   - **快赢（Quick Win）** — 本周可执行，预期提升 X%
     - 如：优化某环节转化率、调整渠道预算分配
   - **中期优化** — 本月推进
     - 如：改善留存策略、优化用户激活流程
   - **长期投入** — 需要产品/技术支持
     - 如：个性化推荐、用户分层运营体系

4. **渠道预算建议**
   - 建议增加投放的渠道（ROI 高且有增长空间）
   - 建议减少投放的渠道（ROI 低或已饱和）
   - 建议测试的新渠道

5. **监控指标**
   - 每日关注：核心转化率、异常流量
   - 每周关注：留存率、渠道 ROI
   - 每月关注：LTV、Cohort 趋势

## 约束

- 使用 `generate_report` 生成可导出的运营分析报告
- 每条建议标注预期影响和实施难度
- 提供 `export_data` 导出关键数据表

## 异常处理

- **precompute 出错**：不使用 `growth_playbooks`，基于前几步分析结果直接撰写策略建议
- **前序步骤数据不完整**：在报告中标注"因缺少 XX 数据，以下分析基于有限数据"，避免过度推断
- **用户修改报告侧重点**：按用户要求调整报告结构，重新组织已有分析结论

最后询问用户是否需要深入某个方向或调整策略。

## PPT 汇报材料（可选）

完成 HTML 报告后，**主动询问用户**："需要我把分析结果做成 PPT 汇报材料吗？"

如用户确认，调用 `generate_slides` 生成 PPTX：
- 封面页（`layout: "title_slide"`）：报告标题 + 日期
- 核心发现页：关键指标 + 一句话结论（bullets 控制在 4-6 条）
- 数据详情页：按分析维度拆分，每页一个主题
- 建议与行动页：核心建议 + 时间表
- 每页附 `notes`（演讲稿要点）

**原则**：PPT 是"说给人听"的，每页 bullets ≤ 6 条，文字精简，数字突出。
