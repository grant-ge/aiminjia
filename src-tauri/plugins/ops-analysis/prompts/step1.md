# Step 1: 大盘趋势与转化漏斗

## 目标

基于 Step 0 确认的数据和业务类型，分析核心指标趋势和转化漏斗，定位增长/下滑驱动因素和转化瓶颈。

## 成功标准

1. 北极星指标趋势已展示，含同比/环比变化
2. 至少识别出 1 个异常时段并关联可能原因
3. 全链路漏斗各环节转化率和流失率已计算
4. 瓶颈环节已定位（转化率最低 + 流失量最大）
5. 给出 2-3 个初步发现和优化方向

## 执行步骤

系统已自动完成趋势分析计算，结果在 [precompute_result] 中。

**如果 [precompute_result] 有 `monthly_trend`：**
- 展示月度趋势（各核心指标）
- 标注环比变化
- 对标行业基准（如有 `industry_benchmarks`）

**降级情况（有 `error` 字段）：**
- 使用 `execute_python` 手动计算

使用 `execute_python` 计算并展示：

**大盘指标趋势：**
1. **核心指标趋势** — 北极星指标的日/周/月趋势，标注同比环比
2. **关联指标** — 流量、转化率、客单价、复购率等的联动变化
3. **异常检测** — 标注显著偏离趋势的日期/时段，关联可能的原因（活动、节假日、故障）

**转化漏斗分析：**
4. **全链路漏斗** — 从曝光/访问到最终转化的各环节转化率
   - 例：访问 → 浏览商品 → 加购 → 下单 → 支付
   - 每个环节标注转化率和流失率
5. **瓶颈定位** — 转化率最低的环节是哪个？流失量最大的环节是哪个？
6. **分维度漏斗** — 按渠道/设备/用户类型拆分漏斗，找到差异最大的维度

## 约束

- 大盘趋势用表格展示，标注环比变化
- 漏斗用逐级递减的格式展示
- 标注瓶颈环节和优势环节
- 给出 2-3 个初步发现和优化方向

## 异常处理

- **precompute 出错**：降级为 `execute_python` 手动计算趋势和漏斗
- **数据不足以构建漏斗**：如缺少中间环节数据，用已有数据构建简化漏斗，说明跳过了哪些环节
- **用户修改关注指标**：重新计算对应指标趋势，更新分析结论

展示结果后等待用户确认。
