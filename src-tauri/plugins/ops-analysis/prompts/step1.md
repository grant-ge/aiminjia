# Step 1: 大盘趋势与转化漏斗

基于 Step 0 确认的数据和业务类型，分析核心指标趋势和转化漏斗。

使用 `execute_python` 计算并展示：

**大盘指标趋势：**
1. **核心指标趋势** — 北极星指标的日/周/月趋势，标注同比环比
2. **关联指标** — 流量、转化率、客单价、复购率等的联动变化
3. **异常检测** — 标注显著偏离趋势的日期/时段，关联可能的原因（活动、节假日、故障）

**转化漏斗分析：**
4. **全链路漏斗** — 从曝光/访问到最终转化的各环节转化率
   - 例：访问 → 浏览商品 → 加购 → 下单 → 支付
   - 每个环节标注转化率和流失率
5. **瓶颈定位** — 转化率最低的环节是哪个？流失量最大的环节是哪个？
6. **分维度漏斗** — 按渠道/设备/用户类型拆分漏斗，找到差异最大的维度

**输出要求：**
- 大盘趋势用表格展示，标注环比变化
- 漏斗用逐级递减的格式展示
- 标注 🔴 瓶颈环节和 🟢 优势环节
- 给出 2-3 个初步发现和优化方向

展示结果后等待用户确认。
