# Step 2: 客户与产品分析

## 目标

基于前面的趋势分析，深入客户和产品维度，识别关键客户和产品的贡献与风险。

## 成功标准

1. 客户分层表已输出（含客户数、金额、占比）
2. Top 客户帕累托分析已完成（前 20% 客户贡献占比）
3. 产品贡献度排名已展示
4. 高风险点已标注（大客户流失、产品下滑）
5. 每个维度至少给出 1 条针对性建议

## 执行步骤

系统已自动完成客户与产品分析，结果在 [precompute_result] 中。

**如果 [precompute_result] 有 `pareto`：**
- 展示帕累托分析（Top 20% 客户贡献占比）
- 客户集中度风险评估
- 产品组合分析

**降级情况：**
- 使用 `execute_python` 手动计算

基于前面的趋势分析，深入客户和产品维度。

使用 `execute_python` 计算并展示：

**客户分析：**
1. **客户分层（RFM 或简化版）** — 按消费金额/频次分为 A/B/C 级
2. **Top 客户贡献** — 前 10/20% 客户贡献了多少销售额（帕累托分析）
3. **客户流失风险** — 近期无复购的高价值客户

**产品分析：**
4. **产品贡献度** — 各产品/品类的销售额占比
5. **产品增长排名** — 增长最快和下滑最快的产品
6. **交叉销售** — 常见的产品组合购买模式

**输出要求：**
- 客户分层用表格展示，标注每层的客户数、总金额、占比
- 产品分析用排名表展示
- 标注需要关注的风险点（如大客户流失、产品下滑）
- 给出针对性建议

展示结果后等待用户确认。

## 约束

- 所有数值来自 execute_python 实际计算结果
- 不展示代码

## 异常处理

- **precompute 出错**：使用 `execute_python` 手动计算客户分层和产品贡献度
- **数据不足**：若缺少客户 ID 字段，跳过客户分层，仅做产品分析；若缺少产品字段，跳过产品分析，仅做客户分析
- **用户修改需求**：用户可要求调整分层标准（如 A/B/C 阈值）或增加分析维度，按需重新计算
