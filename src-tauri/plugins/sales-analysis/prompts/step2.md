# Step 2: 客户与产品分析

基于前面的趋势分析，深入客户和产品维度。

使用 `execute_python` 计算并展示：

**客户分析：**
1. **客户分层（RFM 或简化版）** — 按消费金额/频次分为 A/B/C 级
2. **Top 客户贡献** — 前 10/20% 客户贡献了多少销售额（帕累托分析）
3. **客户流失风险** — 近期无复购的高价值客户

**产品分析：**
4. **产品贡献度** — 各产品/品类的销售额占比
5. **产品增长排名** — 增长最快和下滑最快的产品
6. **交叉销售** — 常见的产品组合购买模式

**输出要求：**
- 客户分层用表格展示，标注每层的客户数、总金额、占比
- 产品分析用排名表展示
- 标注需要关注的风险点（如大客户流失、产品下滑）
- 给出针对性建议

展示结果后等待用户确认。
