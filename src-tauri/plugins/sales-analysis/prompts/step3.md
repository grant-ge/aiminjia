# Step 3: 洞察与建议

综合前面所有分析结果，输出最终报告。

**报告结构：**

1. **核心发现**（3-5 条，每条一句话）
   - 最重要的趋势
   - 最大的风险
   - 最大的机会

2. **关键指标仪表盘**
   - 总销售额、同比增长率
   - 客户数、客单价、复购率
   - Top 产品贡献度

3. **行动建议**（按优先级排序）
   - 短期（本月可执行）
   - 中期（本季度）
   - 长期（需要战略调整）

4. **风险提示**
   - 需要关注的下滑趋势
   - 客户集中度风险
   - 产品结构风险

**输出要求：**
- 使用 `generate_report` 生成可导出的分析报告
- 报告语言简洁、结论导向
- 每个建议都要有数据支撑
- 提供 `export_data` 导出关键数据表

最后询问用户是否需要补充分析或调整报告内容。
