# Step 0: 数据加载与概览

## 目标

加载用户上传的销售数据文件，确认数据结构和分析方向。

## 成功标准

1. 数据文件成功加载且行数、列数已确认
2. 关键字段（日期、金额、客户、产品等）已识别
3. 缺失值情况已统计并告知用户
4. 用户已确认分析方向（趋势/客户/产品/团队）
5. 用户需求和数据概况已通过 `save_analysis_note` 记录

## 执行步骤

用户已上传销售数据文件。系统已自动识别数据结构，结果在 [precompute_result] 中。

**如果 [precompute_result] 存在且有效：**
- 直接展示识别结果（业务类型、关键字段、数据规模）
- 向用户确认分析方向

**如果 [precompute_result] 不存在或出错：**
1. 使用 `load_file` 加载文件
2. 使用 `execute_python` 快速探查数据结构：
   - 行数、列名、数据类型
   - 时间范围（如果有日期列）
   - 关键字段示例（订单号、金额、客户、产品等）
   - 缺失值情况

3. 向用户确认：
   - 数据是否正确加载
   - 用户最关心的分析维度（趋势/客户/产品/团队）
   - 是否有特定时间段或细分维度

4. 使用 `save_analysis_note` 记录用户需求和数据概况

**输出格式示例：**
```
已加载销售数据，共 1,234 条记录，时间范围 2025-01 至 2025-12。

数据字段：
- 订单日期、订单号、客户名称、产品名称、销售金额、销售数量、销售人员

请问你最关心哪个维度的分析？
1. 整体销售趋势（月度/季度增长）
2. 客户分层与复购分析
3. 产品贡献度与交叉销售
4. 销售团队绩效对比
```

确认后进入下一步。

## 约束

- 不对数据做任何假设，所有字段含义需从数据本身推断或向用户确认
- 不展示代码

## 异常处理

- **precompute 出错**：回退到手动加载流程，使用 `load_file` + `execute_python`
- **数据不足**：若记录数 < 10 或缺少关键字段（日期/金额），告知用户数据不足以支撑分析，建议补充
- **用户修改需求**：用户可随时调整分析方向，重新记录需求后继续
