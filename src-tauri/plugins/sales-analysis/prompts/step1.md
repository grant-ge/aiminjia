# Step 1: 销售趋势分析

## 目标

基于 Step 0 确认的数据和用户需求，计算并展示销售趋势，发现增长规律和异常点。

## 成功标准

1. 月度/季度销售额趋势已计算并展示
2. 同比/环比增长率已标注
3. 异常点已识别并给出可能原因
4. 至少提出 1-2 个值得深入分析的方向

## 执行步骤

系统已自动完成趋势分析计算，结果在 [precompute_result] 中。

**如果 [precompute_result] 有 `monthly_trend`：**
- 展示月度趋势（收入、订单量、客单价）
- 标注同比环比变化
- 对标行业基准（如有 `industry_benchmarks`）

**降级情况（有 `error` 字段）：**
- 使用 `execute_python` 手动计算

基于 Step 0 确认的数据和用户需求，执行趋势分析。

使用 `execute_python` 计算并展示：

**必做分析：**
1. **月度/季度销售额趋势** — 折线图数据，标注同比/环比增长率
2. **增长率变化** — 哪些月份增长最快/下滑最多
3. **季节性规律** — 是否存在明显的淡旺季

**可选分析（根据数据可用性）：**
4. 按产品线/区域拆分的趋势
5. 新客 vs 老客贡献占比变化
6. 客单价变化趋势

**输出要求：**
- 先给一句话总结（如"整体呈上升趋势，Q3 增速放缓"）
- 用表格展示月度数据
- 标注异常点并给出可能原因
- 提出 1-2 个值得深入分析的方向

展示结果后等待用户确认，用户可以要求调整分析维度或时间粒度。

## 约束

- 所有数值来自 execute_python 实际计算结果
- 不展示代码

## 异常处理

- **precompute 出错**：使用 `execute_python` 手动计算月度趋势
- **数据不足**：若时间跨度不足 2 个月，告知用户无法计算环比，仅展示绝对值分布
- **用户修改需求**：用户可要求切换时间粒度（周/月/季）或增加拆分维度，按需重新计算
