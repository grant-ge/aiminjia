# Step 0: 数据加载与问卷结构

## 目标

加载问卷数据，识别问卷结构，与用户确认分析方向。

## 成功标准

1. 数据文件已成功加载，样本量和有效回收率已确认
2. 题目类型分布已识别（单选/多选/量表/开放题）
3. 数据质量已评估（缺失值、直线作答、异常短时间）
4. 分析方向和重点关注维度已与用户确认
5. 问卷结构已通过 `save_analysis_note` 记录

## 执行步骤

用户已上传问卷数据文件。系统已自动识别问卷结构，结果在 [precompute_result] 中。

**如果 [precompute_result] 存在且有效：**
- 直接展示识别结果（题目类型分布、样本量、问卷类型、完成率）
- 向用户确认分析方向

**如果 [precompute_result] 不存在或出错：**
1. 使用 `load_file` 加载问卷数据
2. 使用 `execute_python` 识别问卷结构：
   - 题目数量和类型（单选/多选/量表/开放题）
   - 回收量和有效回收率
   - 人口统计学变量（性别、年龄、部门等）
   - 数据质量：缺失值、直线作答、异常短时间
3. 向用户确认分析目标和重点关注的维度
4. 使用 `save_analysis_note` 记录问卷结构

确认后进入下一步。

## 约束

- 不跳过数据质量检查
- 分析方向必须由用户确认，不自行决定

## 异常处理

- **precompute 出错**：降级为手动加载和识别，使用 `load_file` + `execute_python`
- **数据不足**：如样本量过小（< 30），告知用户统计分析的可信度有限，建议补充数据
- **用户修改方向**：更新 `save_analysis_note`，以最新确认的分析方向为准
