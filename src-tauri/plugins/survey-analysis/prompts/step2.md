# Step 2: 交叉分析与洞察

## 目标

完成分群交叉分析，识别显著差异和驱动因素，提取深层洞察。

## 成功标准

1. 各人口统计维度与满意度的交叉对比已完成
2. 统计显著差异已标注（含 p 值）
3. 驱动因素分析已完成（哪些维度对整体满意度影响最大）
4. 开放题分析已完成（关键词提取、情感分析、主题聚类）
5. 结果已展示给用户等待确认

## 执行步骤

系统已自动完成交叉分析，结果在 [precompute_result] 中。

**如果 [precompute_result] 有 `cross_analysis`：**
- 展示各人口统计维度与满意度的交叉对比
- 展示得分最高和最低的群体
- 标注群体差异显著的维度

**降级情况：**
- 使用 `execute_python` 手动计算

1. **分群对比** — 按人口统计学变量交叉分析
2. **显著性检验** — 哪些差异是统计显著的
3. **驱动因素** — 哪些维度对整体满意度影响最大
4. **开放题分析** — 关键词提取、情感分析、主题聚类

展示结果后等待用户确认。

## 约束

- 所有统计检验必须由 `execute_python` 实际执行
- 显著性标注必须基于实际 p 值，不主观判断

## 异常处理

- **precompute 出错**：使用 `execute_python` 手动计算交叉分析和显著性检验
- **数据不足**：某分群样本量过小（< 10）时跳过该分群的交叉分析，告知用户原因
- **用户修改关注点**：按用户要求补充特定维度或群体的深入分析
