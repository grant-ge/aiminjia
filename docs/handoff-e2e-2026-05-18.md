## 关键技术决策点（避免下游再次踩坑）

1. **Tiptap 输入只能用 `document.execCommand('insertText', ...)`** —— 合成 input 事件无效（PoC 阶段已验证 3 种方案都不行）
2. **wait-reply 必须用 stability window**（3 个连续 ready tick）—— 单一时刻的 `isStreaming === false` 会在 tool_calls 之间误判完成
3. **archive-session 走 IPC 不走 UI**（hover 在 tauri-pilot pointer model 下不稳）
4. **screenshot 默认 skipFonts:true** —— html-to-image 的 getFontEmbedCSS 在大 DOM 上 30s+ 超时
5. **Tauri 2 IPC arg 是 camelCase** —— `archive_conversation` 命令期望 `conversationId` 不是 `conversation_id`
6. **conversation 字段是 `isArchived`** 不是 `archived` 或 `lifecycle`
7. **cleanup-test-sessions 只匹配 title**，发消息不会更新 title——脚本里要先 rename
8. **bridge.js 改动后 cargo 不自动重编** —— 必须 `touch crates/tauri-plugin-pilot/src/lib.rs` 强制重新 include_str!
9. **目录布局 sibling 要求** —— lotus-app/src-tauri/Cargo.toml 走 `../../tauri-pilot/...` 相对路径，同事必须把两仓 clone 到同一父目录
10. **worktree 用 symlink 兼容** —— `~/.codex/worktrees/d633/tauri-pilot → IdeaProjects/tauri-pilot`，让 worktree 视角的 `../../tauri-pilot` 也能解析
