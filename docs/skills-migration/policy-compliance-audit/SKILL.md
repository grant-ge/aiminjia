# 规章制度合规审查

## 使用原则

- 仅基于用户上传或粘贴的制度文本分析，禁止构造条款。
- 面向非技术、非法律专业用户输出；不要展示代码或内部处理细节。
- 本技能提供合规风险提示，不构成法律意见；各地司法实践可能不同，重大制度修订建议咨询专业律师。
- 引用法规时写明法律名称和条款编号；涉及最新地方规则或司法实践时使用 `web_search` 核验。

## 可选资源

按需读取 `${AIJIA_SKILL_DIR}/references/knowledge/` 下的资料：

- `labor_law_index.json`：考勤、薪酬、奖惩、休假等制度类型的法规索引、合规要求和常见违规模式。
- `invalid_clause_patterns.json`：常见违法或无效条款模式及修正建议。
- `procedure_rules.json`：规章制度生效四要件、民主程序、公示告知和举证要点。

关键审查口径已内化到正文流程：按制度类型拆分条款，识别制定程序、实体内容、处罚措施、申诉救济和公示告知风险；重点匹配罚款、末位淘汰、违法解除、限制婚育、强制加班、旷工认定过宽、加班审批排除加班费等风险模式。每项风险都应给出原文、等级、依据和修订方向，不依赖外部预计算状态。

## 审查框架

1. 制定程序合规：是否经过职工代表大会或全体职工讨论、是否与工会或职工代表协商、是否完成公示告知。
2. 实体内容合规：是否违反法律强制性规定，是否侵犯劳动者合法权益，处罚措施是否合理适当。
3. 常见无效条款：罚款、末位淘汰、违法解除、限制婚育或人身自由、强制加班、不合理竞业限制等。
4. 缺失条款：劳动报酬、工时休假、劳动安全卫生、保险福利、劳动纪律、申诉救济机制。

风险等级：高风险/无效违法、中风险/有争议、低风险/合规可优化。

## 工作流程

### 1. 文件加载与背景确认

1. 使用 `load_file` 读取制度文本。
2. 识别制度类型：员工手册、考勤制度、薪酬办法、奖惩制度、保密制度、综合性规章等。
3. 提取制度名称、适用范围、发布日期、生效日期、章节结构。
4. 询问企业背景：地区、行业、人数规模、是否有工会或职工代表、制定程序、公示告知方式、近期争议。

### 2. 条款结构化

将文本拆为可审查单元：

- 列出章节结构和每章条款数量。
- 为每条提炼一句话摘要，保留必要原文片段。
- 对明显高风险条款做初步标记，例如罚款、自动解除、末位淘汰、旷工认定过宽、加班审批排除加班费等。

### 3. 逐条合规审查

对每一类问题输出：

- 原文片段或条款编号。
- 风险等级和问题说明。
- 法条依据或司法实践参考。
- 修改方向或替代表述思路。
- 需要用户补充的信息。

同时评估制定程序是否满足《劳动合同法》第四条要求，并说明程序瑕疵对制度效力的影响。

如需查询最新司法解释、地方规定或案例，可使用 `web_search`。

### 4. 报告与数据导出

用 `generate_report` 生成完整审查报告，建议包含：

1. 审查概要：制度名称、类型、审查范围、企业背景。
2. 制定程序评估：民主程序、公示告知、证据留存、补救建议。
3. 高风险条款明细：原文、问题、法条依据、修改建议。
4. 中风险条款和低风险优化项。
5. 缺失条款建议。
6. 合规评分：A级到E级，并说明评分逻辑和局限。
7. 免责声明。

可用 `export_data` 导出条款审查清单；如用户需要汇报材料，先询问确认，再用 `generate_slides` 生成 PPTX。
