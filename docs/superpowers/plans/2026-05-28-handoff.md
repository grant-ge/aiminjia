Plan 假设了 `run_llm_step` 内有 `self.gateway` 可访问，且 `LlmStepInput` 有以下字段：

- `input.anthropic_multimodal_turn`
- `input.trace_id`
- `input.max_tokens`
- `input.run_id`

**这些假设未验证**。新 session 派 subagent 前**先自己 grep 确认**：

```bash
grep -n "pub struct LlmStepInput" src-tauri/src/runtime/chat/turn_config.rs
# 看字段清单

grep -n "impl.*TauriCommands\|self\.gateway" src-tauri/src/transport/tauri_commands/chat.rs | head -10
# 看 run_llm_step 所在 impl 块是否持有 gateway
```

**如果发现字段缺**：
- 选项 A: 扩 LlmStepInput 把缺的字段加上（影响 trait + 所有 impl，工作量中等）
- 选项 B: fallback 不从 input 拿，而是从 run_chat_turn_s4 上层（chat_turn_driver）拿；这意味着 fallback 逻辑要从 run_llm_step 上移到 chat_turn_driver Err(MaxRetriesExceeded) 之后的某个位置

**如果 self.gateway 不可访问**：
- 看 run_llm_step 所在结构体（`TauriChatCommandAdapter`?）是否有 LlmGateway 字段；如果没有，扩字段或通过 input 注入

派 subagent 时**明确说**："如果发现字段不对或 self 上没 gateway，立即 BLOCKED 上报，不要乱猜"。
