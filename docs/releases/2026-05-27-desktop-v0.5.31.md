## Product Changes

- Remote skills, digital employees, and expert teams now sync from the server to the desktop client.
- Digital employees are stored as desktop resources and become directly usable after sync. Desktop no longer exposes hire or uninstall behavior for these remote employees.
- Employee market replaced the previous template market naming and now hosts digital employee sync entry points.
- Skills, digital employees, and expert teams support manual sync, automatic sync, and version display.
- Skill center, skill detail pages, digital employee market, and expert team lists support Chinese and English names/descriptions from synced resource metadata.
- Expert team avatars are hosted on OSS and the desktop resolves remote avatar URLs instead of relying on emoji fallbacks.
- Schedule creation no longer requires selecting a digital employee.

## Operational Notes

- Apple timestamp/notary network failures occurred during macOS packaging. The arm64 DMG was initially notarized and stapled but lacked the outer DMG code signature; it was re-signed with timestamp, re-notarized, re-stapled, re-validated, and re-uploaded.
- `ci-finalize.py` initially produced generic release notes because the local prebuild changelog cache did not contain `0.5.31`. The Lotus home changelog was deployed, the desktop prebuild cache was refreshed, and `update.json` was finalized again.
- Recommended release script improvements:
  - Add `curl --retry --retry-all-errors` style retry behavior to `scripts/verify-release.sh`.
  - Make macOS signing/upload scripts retry Apple timestamp/notary network failures.
  - Validate outer DMG code signatures before upload, including skip-rebuild paths.
  - Let the finalization step fetch live changelog data when the local prebuild cache lacks the requested version.
