## Product Changes

- Fixed image attachments not using the v2 multimodal vision path when legacy `cloud_model` data was still present. Uploaded images now route by attachment capability instead of the deprecated cloud-model concept.
- Fixed Windows digital employee sync failures caused by unsafe template cache directory names. Template IDs containing `:` and other special characters are now encoded into cross-platform-safe cache paths.
- Model listing now refreshes an expired session key and retries once after a `401`, reducing post-login model availability failures.
- macOS release signing/upload handling is more resilient: Apple notary uploads disable S3 acceleration and retry TLS / secure connection failures.
