# MCP 支持实施计划（Plan-G）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 lotus-app 添加 MCP（Model Context Protocol）工具支持，让外部 MCP server 的工具可以动态注册并被 LLM 调用。

**Architecture:** G1 先使 TOOL_CATALOG 动态化；G2 定义 MCP 连接抽象；G3 实现 MCP 工具作为 RuntimeTool；G4 管理 server 生命周期。各步骤顺序依赖。

**Tech Stack:** Rust, tokio, async_trait, JSON-RPC（MCP 协议）

**Worktree branch:** `feat/mcp-support`

---

## 背景

- `TOOL_CATALOG` 当前是 `LazyLock<ToolCatalog>`，启动时初始化后不可变。
- MCP server 工具是动态发现的（通过 `list_tools` RPC），无法在编译时注册。
- ToolRegistry 已有 `register_runtime()` 方法，但缺少与 TOOL_CATALOG 的同步机制。
- 目标是将 MCP 工具作为第一类 RuntimeTool 集成，与 builtin 工具平等对待。

---

## 设计原则

1. **LazyLock → Arc<RwLock> 迁移：** TOOL_CATALOG 改为运行时可变，保持 lazy 初始化行为。
2. **RuntimeTool 优先：** MCP 工具必须实现 RuntimeTool trait，不走 LegacyToolAdapter 路径。
3. **Capability scope `mcp`：** 新增 scope，CapabilityPermissionPipeline 允许通过（MCP 权限由 server 侧管理）。
4. **Mock friendly：** 所有 MCP 交互通过 trait 抽象，便于单测用 mock McpConnection。
5. **无真实 server 依赖：** 测试不启动真实 MCP server，使用内存 mock。
6. **工具名必须 fully-qualified：** 对标 `claude-code-best`，MCP 工具对外暴露名不能是裸 `tool_name`，而必须是 `mcp__<server>__<tool>` 形式，避免与 builtin / 其他 server 工具撞名，并保持 permission rule / analytics / tool pool 刷新语义一致。
7. **dispatcher 名与远端调用名分离：** lotus 内部 dispatcher / catalog / permission 一律使用 fully-qualified 名称；真正发给 MCP server 的 `call_tool(name=...)` 必须使用原始 `tool_name`，不能把 `mcp__...` 直接透传给 server。
8. **生命周期必须支持清理/刷新：** server disconnect / unregister / reconnect 后，必须能移除旧的 runtime tool 与 catalog entry，避免 stale tool pool；对标 claude-code-best 的 MCP client refresh / cleanup 语义。
9. **锁不跨 await：** manager / registry 中涉及 `RwLock` 的代码先 clone 连接和状态，再做 `connect/list_tools/disconnect`，不要持锁跨 `await`。

  pub async fn register_runtime(&self, tool: Arc<dyn crate::runtime::tools::RuntimeTool>) {
      let def = tool.definition();
      let id = def.id.clone();
      
      // 1. Register to dispatcher (existing)
      log::info!("Registering runtime tool: {}", id);
      self.runtime_tools.write().await.insert(id.clone(), tool);
      
      // 2. NEW: Sync to TOOL_CATALOG if not already present
      if TOOL_CATALOG.get(&id).is_none() {
          // Generate minimal JSON schema from definition
          let json_schema = Self::infer_json_schema(&def);
          let entry = CatalogEntry::new(def, json_schema);
          TOOL_CATALOG.register_entry(entry);
          log::info!("Synced runtime tool '{}' to TOOL_CATALOG", id);
      }
  }
  
  fn infer_json_schema(def: &ToolDefinition) -> Value {
      // For builtin tools: schema is already in TOOL_CATALOG
      // For dynamic tools: generate minimal `{"type": "object"}` 
      // Real schema comes from MCP server's tool definition
      json!({ "type": "object", "properties": {} })
  }
  ```

  use async_trait::async_trait;
  use std::sync::Arc;
  use serde_json::Value;
  use crate::runtime::mcp::types::{McpServerConfig, McpToolDefinition};

  /// 错误类型（MCP 连接和调用相关）
  #[derive(Debug, Clone)]
  pub enum McpError {
      ConnectionFailed(String),
      ServerNotResponding,
      ToolNotFound(String),
      ToolExecutionFailed(String),
      InvalidResponse(String),
      AlreadyConnected,
      NotConnected,
  }

  impl std::fmt::Display for McpError {
      fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
          match self {
              McpError::ConnectionFailed(msg) => write!(f, "MCP connection failed: {}", msg),
              McpError::ServerNotResponding => write!(f, "MCP server not responding"),
              McpError::ToolNotFound(name) => write!(f, "MCP tool not found: {}", name),
              McpError::ToolExecutionFailed(msg) => write!(f, "MCP tool execution failed: {}", msg),
              McpError::InvalidResponse(msg) => write!(f, "Invalid MCP response: {}", msg),
              McpError::AlreadyConnected => write!(f, "MCP server already connected"),
              McpError::NotConnected => write!(f, "MCP server not connected"),
          }
      }
  }

  impl std::error::Error for McpError {}

  /// Result type for MCP operations
  pub type McpResult<T> = Result<T, McpError>;

  /// Abstract MCP connection interface.
  ///
  /// Implementations handle JSON-RPC 2.0 communication with an MCP server,
  /// but surface a simple tool-level interface.
  #[async_trait]
  pub trait McpConnection: Send + Sync {
      /// 连接到 MCP server
      async fn connect(&self) -> McpResult<()>;

      /// 断开连接
      async fn disconnect(&self) -> McpResult<()>;

      /// 检查连接是否活跃
      fn is_connected(&self) -> bool;

      /// 获取 server 名称
      fn server_name(&self) -> &str;

      /// 列出此 server 提供的所有工具定义
      async fn list_tools(&self) -> McpResult<Vec<McpToolDefinition>>;

      /// 调用指定工具
      async fn call_tool(
          &self,
          tool_name: &str,
          arguments: Value,
      ) -> McpResult<Value>;

      /// 获取原始配置（用于日志和管理 UI）
      fn config(&self) -> &McpServerConfig;
  }

  pub type SharedMcpConnection = Arc<dyn McpConnection>;
  ```

  ```rust
  use async_trait::async_trait;
  use serde_json::Value;
  use std::sync::Arc;

  use crate::runtime::tools::{
      RuntimeTool, ToolDefinition, ToolResult, ToolError, ToolExecutionContext,
  };
  use crate::runtime::mcp::connection::{McpConnection, SharedMcpConnection};

  /// 通用 MCP RuntimeTool 实现。
  ///
  /// 包装一个 McpConnection 并将工具调用转发到远程 MCP server。
  pub struct McpRuntimeTool {
      definition: ToolDefinition,
      connection: SharedMcpConnection,
      server_name: String,
  }

  impl McpRuntimeTool {
      pub fn new(
          definition: ToolDefinition,
          connection: SharedMcpConnection,
          server_name: String,
      ) -> Self {
          Self {
              definition,
              connection,
              server_name,
          }
      }
  }

  #[async_trait]
  impl RuntimeTool for McpRuntimeTool {
      fn definition(&self) -> ToolDefinition {
          self.definition.clone()
      }

      fn is_concurrency_safe(&self, _input: &Value) -> bool {
          // MCP tools are typically stateless; default to allowing concurrency
          // Individual tools can override via check_permissions() if needed
          true
      }

      fn is_read_only(&self, _input: &Value) -> bool {
          // MCP tools are opaque; assume read-only unless overridden
          self.definition.default_read_only
      }

      fn is_destructive(&self, _input: &Value) -> bool {
          self.definition.default_destructive
      }

      async fn check_permissions(
          &self,
          _input: &Value,
          _ctx: &ToolExecutionContext,
      ) -> Option<crate::runtime::tools::permission::PermissionDecision> {
          // Permissions checked by CapabilityPermissionPipeline via mcp scope
          None
      }

      async fn execute(
          &self,
          input: Value,
          ctx: ToolExecutionContext,
      ) -> Result<ToolResult, ToolError> {
          // Ensure connection is active
          if !self.connection.is_connected() {
              return Err(ToolError::ExecutionFailed(format!(
                  "MCP server '{}' is not connected",
                  self.server_name
              )));
          }

          // Call remote tool
          let tool_name = &self.definition.id;
          let result = self
              .connection
              .call_tool(tool_name, input)
              .await
              .map_err(|e| ToolError::ExecutionFailed(e.to_string()))?;

          // Wrap result as ToolResult
          Ok(ToolResult {
              content: result.to_string(),
              data: Some(result),
          })
      }
  }

  impl Clone for McpRuntimeTool {
      fn clone(&self) -> Self {
          Self {
              definition: self.definition.clone(),
              connection: self.connection.clone(),
              server_name: self.server_name.clone(),
          }
      }
  }

  // Ensure it can be cast to Arc<dyn RuntimeTool>
  impl std::fmt::Debug for McpRuntimeTool {
      fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
          f.debug_struct("McpRuntimeTool")
              .field("name", &self.definition.id)
              .field("server", &self.server_name)
              .finish()
      }
  }
  ```

  /// 
  /// 1. List tools from the server via McpConnection
  /// 2. Create McpRuntimeTool for each
  /// 3. Register in TOOL_CATALOG and dispatcher
  pub async fn register_mcp_server(
      &self,
      connection: Arc<dyn crate::runtime::mcp::McpConnection>,
  ) -> Result<usize, String> {
      use crate::runtime::mcp::McpRuntimeTool;
      use crate::runtime::tools::CatalogEntry;

      // Ensure connected
      if !connection.is_connected() {
          connection.connect().await
              .map_err(|e| format!("Failed to connect MCP server: {}", e))?;
      }

      let server_name = connection.server_name().to_string();

      // List tools
      let mcp_tools = connection.list_tools().await
          .map_err(|e| format!("Failed to list MCP tools: {}", e))?;

      let mut registered = 0;
      for mcp_def in mcp_tools {
          let entry = mcp_def.to_catalog_entry();
          TOOL_CATALOG.register_entry(entry);

          let rt_tool = Arc::new(McpRuntimeTool::new(
              mcp_def.to_tool_definition(),
              connection.clone(),
              server_name.clone(),
          )) as Arc<dyn crate::runtime::tools::RuntimeTool>;

          self.register_runtime(rt_tool).await;
          registered += 1;
      }

      log::info!("Registered {} tools from MCP server '{}'", registered, server_name);
      Ok(registered)
  }

  use std::collections::HashMap;
  use std::sync::Arc;
  use tokio::sync::RwLock;
  use crate::runtime::mcp::connection::{McpConnection, McpError, McpResult, SharedMcpConnection};
  use crate::runtime::mcp::types::McpServerConfig;

  /// 管理多个 MCP 服务器连接的生命周期。
  pub struct McpServerManager {
      connections: Arc<RwLock<HashMap<String, McpServerInfo>>>,
  }

  struct McpServerInfo {
      connection: SharedMcpConnection,
      config: McpServerConfig,
      connected: bool,
      reconnect_attempts: u32,
      max_reconnect_attempts: u32,
  }

  impl McpServerManager {
      pub fn new() -> Self {
          Self {
              connections: Arc::new(RwLock::new(HashMap::new())),
          }
      }

      /// 注册一个新的 MCP server（不立即连接）。
      pub async fn register(
          &self,
          connection: SharedMcpConnection,
          config: McpServerConfig,
      ) -> McpResult<()> {
          let mut conns = self.connections.write().await;
          
          let server_name = config.name.clone();
          if conns.contains_key(&server_name) {
              return Err(McpError::AlreadyConnected);
          }

          conns.insert(
              server_name,
              McpServerInfo {
                  connection,
                  config,
                  connected: false,
                  reconnect_attempts: 0,
                  max_reconnect_attempts: 3,
              },
          );

          Ok(())
      }

      /// 连接指定的 MCP server。
      pub async fn connect(&self, server_name: &str) -> McpResult<()> {
          let mut conns = self.connections.write().await;

          let info = conns
              .get_mut(server_name)
              .ok_or_else(|| McpError::ConnectionFailed(format!(
                  "MCP server '{}' not registered",
                  server_name
              )))?;

          info.connection.connect().await?;
          info.connected = true;
          info.reconnect_attempts = 0;

          log::info!("Connected to MCP server: {}", server_name);
          Ok(())
      }

      /// 断开指定的 MCP server。
      pub async fn disconnect(&self, server_name: &str) -> McpResult<()> {
          let mut conns = self.connections.write().await;

          let info = conns
              .get_mut(server_name)
              .ok_or_else(|| McpError::ConnectionFailed(format!(
                  "MCP server '{}' not registered",
                  server_name
              )))?;

          info.connection.disconnect().await?;
          info.connected = false;

          log::info!("Disconnected from MCP server: {}", server_name);
          Ok(())
      }

      /// 获取服务器连接（如果已连接）。
      pub async fn get_connection(&self, server_name: &str) -> McpResult<SharedMcpConnection> {
          let conns = self.connections.read().await;

          let info = conns
              .get(server_name)
              .ok_or_else(|| McpError::ConnectionFailed(format!(
                  "MCP server '{}' not registered",
                  server_name
              )))?;

          if !info.connected {
              return Err(McpError::NotConnected);
          }

          Ok(info.connection.clone())
      }

      /// 列出所有已注册的 server。
      pub async fn list_servers(&self) -> Vec<McpServerInfo> {
          let conns = self.connections.read().await;
          conns
              .values()
              .map(|info| McpServerInfo {
                  connection: info.connection.clone(),
                  config: info.config.clone(),
                  connected: info.connected,
                  reconnect_attempts: info.reconnect_attempts,
                  max_reconnect_attempts: info.max_reconnect_attempts,
              })
              .collect()
      }

      /// 卸载一个 server（断开并移除）。
      pub async fn unregister(&self, server_name: &str) -> McpResult<()> {
          let mut conns = self.connections.write().await;

          if let Some(info) = conns.get_mut(server_name) {
              if info.connected {
                  let _ = info.connection.disconnect().await;
              }
          }

          conns.remove(server_name);
          log::info!("Unregistered MCP server: {}", server_name);
          Ok(())
      }

      /// 连接所有已注册的 server。
      pub async fn connect_all(&self) -> Vec<(String, McpResult<()>)> {
          let conns = self.connections.read().await;
          let mut results = Vec::new();

          for (name, info) in conns.iter() {
              let result = info.connection.connect().await;
              results.push((name.clone(), result));
          }

          // Update connected state
          drop(conns); // Release read lock
          for (name, result) in &results {
              if result.is_ok() {
                  let mut conns = self.connections.write().await;
                  if let Some(info) = conns.get_mut(name) {
                      info.connected = true;
                  }
              }
          }

          results
      }

      /// 断开所有已连接的 server。
      pub async fn disconnect_all(&self) -> Vec<(String, McpResult<()>)> {
          let mut conns = self.connections.write().await;
          let mut results = Vec::new();

          for (name, info) in conns.iter_mut() {
              if info.connected {
                  let result = info.connection.disconnect().await;
                  results.push((name.clone(), result));
                  info.connected = false;
              }
          }

          results
      }
  }

  impl Default for McpServerManager {
      fn default() -> Self {
          Self::new()
      }
  }
